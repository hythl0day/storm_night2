# 《暴风夜》节目计划 v2（普通节目路线）

> 本文档是当前执行口径，取代 `show-bible.md`（冻结为旧规划留档，不删不改——里面的戏中戏主线、两季结构、觉醒弧全部暂停）。
> 战略收缩的推理链（2025 讨论）：戏中戏主线剥离 → 单 POV 纪律解除（狄西焦点不成立：976488 里他第 1 天晚即死）→ 格式转为**上帝视角解说的 AI 智斗节目** → 制作回到试播集验证过的路径（立绘 + 手工剪辑 + 剪映音色），Seedance 减到最少。

## 1. 格式定义

**一句话**：主神（黑影主持人）解说的"六个真实 AI 互相残杀"对局实况——上帝视角、全员内心独白并置、台词全部来自真实对局存档。

- **视角**：全程上帝视角（主神 = 解说者，设定上他是裁决者，天然全知）。悬念来自反讽（观众知道谁是杀手，看平民会不会看穿），不来自保密。
- **核心资产**：**内心独白并置**——角色台面上礼貌发言、内心在计算灭口，"说一套想一套"同屏对照。这是任何人类真人秀生产不出来的内容，也是 USP 的真正落点（"你能看到 AI 在想什么"）。
- **焦点角色**：每集一个，剪辑上的情感锚点（内心独白给特写、群像给他人），**必须能驱动剧情深入**——早死者一律不能当焦点。注意焦点角色≠POV 锁死，只是剪辑权重。
- **主神纪律修正**：保留"不解释规则"的精神，但从"绝不解释"放宽为**体育转播式即时解说**——机制首次触发时一句话点明（"注意，停电期间监控不记录"），绝不做开场 lecture。
- **信任状**：片头一句声明（"每一句台词都是 AI 当场生成"）+ 片尾存档证据上屏（script.md / inner.md 片段）。无元叙事宣称。

## 2. 试播集复盘结论的重新归因（video_script.md）

制作路径（立绘+手剪+剪映音色）**无罪**，继续沿用。失败全在内容策略，逐条对照新格式已有解：

| 旧病 | 新解 |
| ---- | ---- |
| 开场 50 行规则说明书 | 主神开场 ≤25s 只说三件事（六个真实 AI / 没有剧本 / 本集看点）；规则全部由事件演示 + 即时解说 |
| 台词虽由 AI 生成，但成片没有任何元素让观众意识到 | 台词来源不变（AI 生成 → 人工润色），但 USP 必须可见：片头声明 + 片尾存档证据上屏 |
| 查特名义 POV 全程被动 | 上帝视角 + 焦点角色剪辑权重，无 POV 锁 |
| 两次平票零结果、无爆发时刻 | 选集标准把关（见 §4） |
| 谋杀全画外 | 谋杀戏 = 静帧/剪影 + 音效 + 震屏（L2）；最多 1–2 个 Seedance 钱镜（L3） |
| 品控事故（智璞/仟文、道具漂移） | 素材管线化：canon 立绘 + 台词从存档导出，事实以存档裁决为准 |
| 采访最好但太浅 | 赛后采访保留为常规综艺环节（无记忆泄漏设定），每集 1–2 问，问"你当时为什么这么做" |

## 3. 制作管线（手工剪辑中心）

原则：**视频生成减到最少，主要生产手工剪辑所需的素材包。**

素材包清单（按集复用度排序）：

| 素材 | 制作方式 | 状态 |
| ---- | ---- | ---- |
| 8 席 canon 设定图 | GPT Image ✅ | 完成（`media/anime/characters/`） |
| 透明底立绘（正面半身/全身） | 剪辑软件人工抠图 或 `--transparent` 直出 | ⬜ |
| 表情差分（通常/微笑/惊愕/愤怒/冷汗/得意） | canon 裁表情格 + edit 模式扩姿势 | ⬜ |
| chibi 差分（颜艺/搞笑专用，不进过场） | canon edit 转 Q 版 | ⬜ |
| 场景背景（会客室/卧室/书房/监控室/地下室/走廊） | GPT Image 二次元室内全景 | ⬜ |
| 字幕卡/证物卡/对话框模板 | 剪辑工程内模板 | ⬜ |
| 配音 | 剪映自带音色（每席固定一个，沿用试播集音色表思路） | 已验证可用 |
| 音效库 | 逆转裁判式：推进音/惊愕重音/证物卡音/唱票鼓点 | ⬜ 收集 |
| L3 视频（最多 1–2 镜：谋杀夜/死亡回放） | Seedance，手写长 prompt；不过则 L2 静帧+音效兜底 | ⬜ 冒烟后定 |

**执行节奏**：台词从存档导出 → 按制作脚本格式（§3.1）整理 → 逐句配剪映音色 → 手工剪辑（立绘切换/特效/镜头推拉）→ 主神解说本人配音 → 片尾存档证据。

### 3.1 制作脚本格式（台词整理规范）

台词来源不变：**AI 生成 → 人工润色**（措辞可改、意图与事实不可歪曲）。润色后整理为双用途制作脚本——同一份文档同时服务字幕剪辑与未来 TTS 配音：

```markdown
## 场 N · <场景名>（<地点>）
[画面: 会客室全景 → 智谱立绘切指向差分] [特效: 证物卡翻转]

# 智谱(沉稳男声)
> src: selected/<id>/public/log.md 第3天·公共发言 | inner: private/glm/inner.md 同段
> tts: 冷静，语速偏慢，尾句加重
各位昨晚的监控
我已经看完了
进入千问卧室的
是智谱

# 主神(本人配音)
> src: 手写（唯一手写通道）
注意，监控只记录"谁进入了房间"
不记录房间里发生了什么
```

规则：

- **分句**：每行 = 一条字幕，目标 ≤15 字、最长 20 字；按语气停顿切，不按标点切。
- **角色块头**：`# 角色(音色)`——音色沿用剪映音色名；主神块是唯一允许手写的台词位（解说/转场）。
- **元信息行**（`>` 引用行）：`src` 必填（存档文件+阶段，内心独白注 inner）；`tts` 预留给火山 TTS（情绪/语速/音色提示，待用户供文档后细化）；两者进备注不进成片。
- **画面/特效指令**：方括号行，供剪辑定位（立绘差分、特效、镜头推拉）。
- **润色核对**：润色稿与存档原句并置备查（沿用旧分镜纪律），事实口径以存档裁决为准。

## 4. 选集标准（E1 重选，976488 不再默认）

用 scorecard 扫 `selected/` 池，按新标准评：

1. **上帝视角可读性**：阴谋线清晰、因果链观众跟得上；
2. **反派线戏剧性**：密谋频道内容精彩、有背叛/反杀/翻车时刻；
3. **焦点角色候选**：至少一名角色深入驱动剧情（杀手或侦探皆可）；
4. **规则教学覆盖**：自然展示投票/谋杀/调查等核心机制（事件演示，不靠解说）；
5. **时长可压缩**：能剪进 8–12 分钟，平票/僵局段少；
6. **内心独白质量**：inner 通道有戏（这是并置演出的原料）。

## 5. 节奏纪律（抖音语法）

- 前 3 秒：冲突画面 + 主神一句钩子（不讲规则）；
- 每 15–20 秒一个小 turn（指控/新证据/立场反转）；
- 单场戏无变化不超过 ~45 秒；
- 谋杀与死亡必须"可见"（静帧+音效也算可见，画外公告不算）；
- 结尾：采访 1–2 问 + 存档证据上屏。

## 6. 验证关口（按序）

1. **E1 重选集**（§4 标准，scorecard 扫 selected/）；
2. **60–90s 测试片段**：用当选局的 Detective 竞选/指控段，L1 立绘 + 剪映音色 + 手工剪辑——验证节奏纪律与台词承载力；
3. **L3 冒烟**（可选，1 镜）：谋杀夜剪影镜头；不过则全片 L2，Seedance 归零也行；
4. 测试片段通过 → 完整分镜表 → 制作 E1 → 发布 → 看完播率与评论再议下一集。

## 7. 明确不做

- 戏中戏主线、轮回、记忆泄漏、觉醒伏笔（留作未来"另类节目"选项：观众懂规则后，以克劳德觉醒做独立节目——不靠伏笔接力，靠格式迭代）；
- 兜帽人/橱窗推镜等 S2 母题；
- 多局混剪（看海集锦是另一种格式，单局验证完再说）；
- 火山 TTS 接入暂缓（E1 用剪映音色；用户后续提供火山文档后再研究，制作脚本已预留 `tts` 提示位）；
- 真人配音、电影质感、全片视频化。
