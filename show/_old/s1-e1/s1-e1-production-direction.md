# S1E1 制作方向决策（2025 年讨论纪要）

> 背景：对项目可行性的一次总体讨论。结论是**不换方向、砍范围、先验证一集**。本文档记录决策与依据，作为回家换机后继续工作的入口。

## 1. 方向决策：维持类型 1（AI 智斗），不倒向纯类型 2（短剧）

三种候选类型的风险结构：

| 类型 | 竞争维度 | 对我们的风险结构 |
| ---- | ---- | ---- |
| 1. AI 智斗 | AI 真实发挥的戏剧性 | 拥挤，但既有资产（跑局管线/存档/六模型同局）直接构成差异化 |
| 2. 纯短剧 | 故事 + 画面 | **最不利**：恰好撞上制作者弱项（剪辑/后期），且 AI 参演在此赛道零优势，对手是工业级团队 |
| 3. 真人秀 | 剪辑/后期 | 同样撞上弱项 |

**决策**：不转向。把 AI 从卖点降级为彩蛋、主攻电影质感短剧的方案被否——那等于放弃全部护城河，带最弱的牌进最拥挤的赛道。

## 2. "AI 是卖点"的正确定位：钩子，不是留存

- 观众反感 AI 的机制是"AI 冒充人的创作"；本项目中 AI 是**出演者**（参照 AI 围棋/星际比赛），诚实是内核，不存在冒充问题。
- 但观众只为结果付费：「台词全是 AI 当场生成」是 3 秒点击钩子（片头声明），**不负责留存**。留存靠戏剧本身（选局 + 剪辑）。
- 分工：AI 真实性 = 信任状 + 传播素材（可审计存档经得起质疑）；戏剧性评分与选局硬条件比制作技术更重要。

## 3. 试播集失败的重新归因：路线未被证伪，执行被证伪

- §7 的 8 条教训（USP 不可见 / 说明书开场 / 主角被动 / 冲突平地化 / 谋杀戏画外 / 推理链不闭合 / 品控事故 / 采访太浅）**没有一条指向"立绘形式不行"或"画面不够电影感"**——全部是叙事结构、选材、包装问题。
- "点击率差"本身是包装指标（封面/标题/前 3 秒），类型 1 或 2 都救不了，对症的是 §0 片头快剪语法（危机瞬间 flash-forward、永不泄底）。
- 保留：n=1 冷启动无法完全归因。做法 = 新一集**修掉 8 条已知问题、保持形式不变**，控制变量拿第二个数据点。

## 4. E1 形制（已定）

- **整体**：动漫角色立绘 + 简单动效 + 配音（"动漫短剧质感"，匹配剪辑能力上限；storm-media 的 canon 立绘管线即为此建）。
- **砍掉**：电影质感开场、全程真人质感。
- **开场结构仍要换**：旧开场的问题是"说明书"而非"不够炫"。新开场 = 死亡教学冷开场（死亡瞬间 flash-forward 再倒带）+ 主神 10 秒声明，立绘 + 字幕卡 + 音效即可。
- **视觉预算集中**：谋杀瞬间 / 死亡发现 / 投票唱票等爆发点用 Seedance 生成视频兑现（教训 5：谋杀戏缺席是恐怖类型最贵失误）；对话戏用立绘差分 + 镜头推拉。原则：全身粗布、刀刃开锋。

## 5. 范围削减：承诺减到一集

- 只做 S1E1，目标 = **做完并发布**；成功/失败指标看完播率与评论质量（冷启动播放量说明不了什么）。
- E1 需要的最小集：已定素材 976488 + 狄西单一 POV + 最低形态片头片尾（静态图 + 配音）。**不需要**：看海单集、8 人局、走廊戏、S2 的任何承诺。
- S2 相关（rules-8 引擎、信号劫持、终局、M7 人机模式）在 E1 验证前**一字不动、一行代码不写**——当前它们是负债不是资产。

## 6. AI 台词生硬问题：实测，不纸面论证

- 台词纪律本就允许"措辞修剪润色、意图与事实不可歪曲"（真人秀行业惯例）；内心独白 + 采访 confessional 是演技不足时的补情绪通道。
- **行动项**：用 s1-e3（947511）存档中克劳德独活段落，剪一个 60–90 秒最低成本测试片段（立绘 + 字幕 + 配音），亲验台词撑不撑得住。

## 7. 制作管线（最终形态，待冒烟验证）

**四步管线：**

1. **Seedream**：二次元 canon 立绘 + 表情/动作差分库（一次性投入，跨集复用）。现有真人风格 canon（claude-sheet.png）作废重做，8 席全部重新生成；注意人脸信任链 30 天有效期，量产开始时集中生成。
2. **Seedance**：对话戏的角色动作动画 + 台词直出（`{存档台词}` 对嘴）；prompt 模板化，首帧/参考素材取差分库（定表情基调、提高抽卡命中率）。
3. **人工剪辑（只做组装，不做逐帧）**：Galgame 对话框字幕 + 反应特效（震屏/闪光/速度线）+ 拼接节奏。
4. **全过场动画**：片头片尾 + 谋杀/死亡发现/唱票等关键事件（全片个位数镜头，手写长 prompt，抽卡预算集中于此）。

**风格基线（已定稿，待写入 `media/style.md`）**：日本动漫二次元风（萌系、不贴合现实）。参照系 = 对话演出学**逆转裁判**（指控=異議あり、冲击帧、反应差分），整体氛围学**弹丸论破**（萌系 × 杀人游戏 × 裁决演出的反差即卖点）。原"真人 vs 动漫试点对比"取消。

**工作流自动化方向**（核心资产 = 结构化存档）：`存档（script.md）→ 分镜表（自动生成）→ 模板化 prompt（自动填充）→ 批量生成 → 机械拼接`。人的工作 = 选戏 + 审分镜表 + 审片。

**差分库的双重职责**：Seedance 首帧/参考素材 + 零成本兜底（某段对话反复抽不出合格品时，差分 + 对话框直接顶上）。差分用 Seedream Pro 图生图从 canon 产出（通常/惊愕/愤怒/冷汗/得意/沉思 × 摊手/指向/抱臂等）。

**验证关口（按序）**：① 5s 冒烟：新二次元 canon + 会客室场景 + `{存档台词}`（链路/人脸信任链/动漫风口型一次验证）；② 用 976488 一段真实对话走完整流程，记录**模板复用率与返工率**（工作流生死指标）。批量视频生成前报价确认（成本闸）；优先实测 draft 480p 草稿模式省钱。若模板路线不成立，回退 = 对话戏纯差分 + 爆发点生成视频。

## 8. 待定方向：Steam Galgame（纯探讨结论，不立项）

- **三种形态**：A. 固定剧本（把跑局素材改写成剧本，人狼村之谜式）——最弱，AI 沦为代笔、护城河消失、竞争撞上弱项；B. **运行时 AI（玩家 = 真人席位 + 5 个真 AI 对局）——真正忠于项目的形态，市面上无此产品**；C. 混合（固定元剧情 + 节点间真实 AI 对局）——兼得但工程量最大。
- **B 的现成基础**：dev-plan M7（hostseat 人机模式）即其原型；已有 Galgame 引擎框架负责呈现层，跑局管线负责游戏本体，接口天然存在。Steam AI 披露针对"AI 冒充人写"，运行时 AI 对抗是玩法特性而非污点。
- **B 的死穴是商业模式不是工程**：API 成本谁付（玩家自备 key / 中转服务器按局摊销 / 本地小模型——均有明显代价）。每局成本可从 scorecard token 统计估算。
- **端侧模型路线（旧游戏项目已验证 llama.dll 接入，Gemma 简单对话可用）暂不成立**：① 本游戏要求四通道 JSON + 合法动作菜单，量化小模型的非法动作率会把兜底重试变成常态，拖垮节奏且破坏公平；② 单模型分饰五角 = 同一演员戴五顶假发，"六家模型行为指纹差异"的 USP 归零。**重启触发条件**（任一满足）：a) 端侧模型结构化输出合法率足够高（可用本项目简报+引擎测试套件直接量化）；b) 端侧模型能稳定维持差异化人设；c) 云端 token 价格跌到可按局摊销进售价。
- **结论：游戏方向停留在纯理论，不立项**。短视频先行 = 验证内容 + 积累 Steam 最缺的受众；二次元 canon/差分/场景/UI 资产两边完全共用。若未来重启，序列：M7 人机模式（兼作游戏 demo）→ demo 实测手感与单局成本 → 再议 Steam 立项。

## 9. 下一步清单（按序）

1. Seedance 冒烟两步（§7-①②）。
2. 60–90 秒台词测试片段（§6）。
3. 若通过：把 E1 按「死亡教学冷开场 → 狄西 POV 正片 → 片尾采访」拆分场大纲，每场标注素材来源（976488 存档段落）与制作规格（立绘 / 生成视频 / 字幕卡）。
4. 按大纲制作 E1，发布，记录数据，再议局 2。
