# 《暴风夜》节目计划 v3（短片连载路线）

> 当前执行口径。取代 v2 长片方案（`_old/show-plan-v2.md`）；更早的戏中戏主线、两季结构、试播集脚本等全部归档 `_old/`，不删不改。
> 决策背景（2025 讨论）：制作者只有下班时间；长片（8–12 分钟单集）周期 2–3 个月且抖音对长视频不友好；去年试播集的真正教训是 USP（"你能看到 AI 在想什么"）从未以可感知的形式上过片——因此放弃长片，改为**一局游戏切成 4–6 条 60 秒竖屏短片的合集连载**，第一条片即验证闸。

## 1. 格式定义

**一句话**：60 秒竖屏短片，一条讲一个事件（竞选/谋杀/投票/背叛），同一局按时间顺序连发，合集追更。

- **视角**：全程上帝视角，**事先让观众知道谁是杀手**。这不是选择题——内心独白并置天然锁死全知；悬念是"她会怎么演、会不会被看穿"（倒叙推理），不是"谁是凶手"。
- **核心资产**：**内心独白并置**——台面发言与 inner 同屏对照（"说一套想一套"）。这是 USP，每条片都要砸在观众脸上。
- **主神** = 解说者 = 用户本人配音；体育转播式，机制首次触发时一句话点明，绝不做 lecture。
- **信任状**：固定开场白内含"台词和内心都是 AI 当场生成"；合集简介注明完整存档可查。

## 2. 铁律

1. **永不解释规则，只交代当前赌注。** 每条开头最多 3 行字卡（"杀手有两个 / 现在竞选侦探 / 赢家拿桌上唯一的枪"）。用不到的机制观众永远不需要知道。
2. **无开场戏。** 失忆、古堡、醒来——全部压缩进固定开场白一个从句（"六个世界顶级 AI 失去记忆，被扔进一座古堡"），约 3 秒。scene.py 开场惊魂补拍**砍掉**（管线保留备用，本路线不用）。
3. **每条 5 秒内完成 USP 演示。** 第一条的钩子：黑屏出内心金句 → 切台面装可怜立绘 → "说这两句话的，是同一个人。"
4. **剪"戏"不剪"证据链"。** 跳过无贡献的平民发言；但后面会被引用的话要留一句或用字卡补述。压缩/跳剪/措辞润色可以，编造与倒置因果不行——每条台词必须能指回存档。
5. **焦点角色制。** 892516：豆包主线 + 克劳德暗线；其他角色只在推动主线时出场。出场角色越少，配音与立绘制作量越低。
6. **结尾必有钩子**（"当天夜里，古堡停电了"），服务合集追更。

## 3. 单条结构模板（~60s）

```
钩子（≤5s）→ 固定开场白一句（~3s）→ 赌注字卡 ≤3 行（~6s）
→ 正片：事件对白 + 内心并置（~30s，L1 立绘+对话框 / L2 静帧+音效）
→ 结果揭晓（~5s）→ 下条钩子（~5s）
```

画面层级沿用旧定义：L1 = 立绘+差分+Galgame 对话框（主体）；L2 = 静帧+震屏/音效（谋杀、指控等爆发点）；L3 生成视频本路线不做。配音沿用剪映音色（每席固定一个），主神本人录音。台词整理沿用 `_old/show-plan-v2.md` §3.1 的分句格式（每行 ≤15 字，`>` 元信息行注 src 出处）。

## 6. 验证闸与判定标准（发片前定死，不许事后解读）

- **先做且只做第 1 条（侦探竞选）**，发出去。
- **看什么**：完播率（不看绝对播放量，新号播放是随机数）；评论里有没有针对形式本身的反应（"这真是 AI 想的？""怎么做到的"）；有没有人说想看下一条。
- **算赢**：完播正常 + 出现零星形式反馈 → 按节奏连发整局（日更或隔日更，稳定节奏 > 单条质量）。
- **算输**：无反应 → 换标题/封面重发一次排除曝光问题 → 仍无反应则形式证伪，项目干净封存。两种结果都是答案，不允许悬置。
- 长片正片门槛：连载数据达标（连续多条稳定反馈）之前不回头做。
