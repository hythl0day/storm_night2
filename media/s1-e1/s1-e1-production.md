> 旧分镜 `s1-e1-storyboard.md` 保留不删：开场惊魂 beats 与 scene.py 改造清单仍有效；冷开场四镜头（雨夜都市/兜帽人/橱窗推镜）冻结。

## 1. 形式定位：有声视觉小说 + 上帝视角解说

参照系 = 视觉小说/动漫实况（逆转裁判式对话演出 + 弹丸论破式氛围），叙事视角 = **主神上帝视角解说**（体育转播式：机制首次触发时一句话点明，绝不做开场 lecture）。

形式与素材的三个契合点：

1. **AI 台词 = 配音脚本**：对话框里每个字都可出示存档；
2. **内心独白并置**：角色台面发言与 inner 同屏对照（"说一套想一套"）——全知视角才解锁得了的核心资产，USP 的真正落点；
3. **存档直接上屏**：片尾放原始日志片段，零成本信任状可视化。

## 2. 节目语法

| 元素 | 实现 |
| ---- | ---- |
| 开场 | 第一人称口播（制作者本人声音）+ 本集 6 席角色卡（前景立绘+名字，背景氛围 CG，Ken Burns 平移）——开场白同时完成角色认脸；无黑影出镜；含声明"每句台词都是 AI 当场生成" |
| 片头声明 | 含在主神介绍内："你听到的每一句台词都是 AI 当场生成" |
| 视角纪律 | 全程上帝视角，不混限制视角（试播集教训 3 的真因是"混"，不是"全知"） |
| 焦点角色 | 每集一名，剪辑权重锚点（inner 给特写）；必须能驱动剧情深入，早死者出局 |
| 主神纪律 | 只评论真实；规则不做 lecture，允许机制首次触发时即时解说 |
| 片尾 | 赛后采访（常规综艺环节，1–2 问"你当时为什么这么做"）+ 存档证据上屏 |
| 教学 | 规则由事件演示 + 即时解说，无说明书 |
| 包装口径 | **不向观众提特权席存在**（deal 配置无需交代）；主神可吐槽 AI 表现（格式资产："每一步都深思熟虑地计算，然后精致地翻车"）；剪辑纪律 = 剪掉克劳德台词里一切"知道得太多"的痕迹（她的简报是 full 口径，引用残页玩家不知的规则细节会让观众起疑） |

## 4. 画面层级系统

| 层级 | 规格 | 用途 | 占比 |
| ---- | ---- | ---- | ---- |
| L0 | 字幕卡 + 音效 | 公告、时间卡 | 随意 |
| L1 | 立绘 + 表情差分 + 对话框（Galgame UI） | 全部对话戏 | 主体 |
| L2 | L1 + 反应特效（震屏/闪光/速度线/证物卡） | 指控、惊愕、调查宣读、谋杀（静帧+音效即"可见"） | 点缀 |
| L3 | Seedance 生成视频 | **最多 1–2 镜**（谋杀夜/死亡回放）；冒烟不过则归零 | 可省 |

L1 引擎 = 差分库：每席「通常/微笑/惊愕/愤怒/冷汗/得意」×「摊手/指向/抱臂」，对话框 + 立绘切换完成全部对话演出；chibi 差分专供颜艺/搞笑（仅对话用，不进过场）。

## 5. 声音方案

- **主神**：用户本人录音。
- **AI 角色**：**剪映自带音色**（试播集已验证可接受，音色词汇表可复用：柔和男声/成熟御姐/御姐语录/慵懒男声/纯真少女等），每席固定一个音色。火山 TTS 暂缓——用户后续提供文档后再研究；制作脚本已预留 `tts` 提示位（show-plan §3.1）。
- **对口型**：架构性消解——对话戏走静态立绘 + 对话框（观众不期待嘴动），L3 钱镜无台词（音效叙事），不做任何唇形同步。
- **音效**：逆转裁判式——对话推进音/惊愕重音/证物卡音/唱票鼓点；谋杀夜以音效叙事为主。

## 7. 验证序列（按序）

1. ~~E1 重选集~~ ✅ 完成：E1 = `selected/892516`（见 §3 回填）；
2. **60–90s 台词测试片段**：用 892516 侦探竞选段（狄西 vs 豆包对决，含 inner 并置），L1 立绘 + 剪映音色 + 手工剪辑——验证节奏纪律与台词承载力；

4. 测试片段通过 → 完整分镜表（三级标注 `[实拍]`/`[补拍]`/`[手写]`，原句与润色稿并置；台词整理用 show-plan §3.1 制作脚本格式）→ 制作。

## 8. 明确不做

- 戏中戏主线、轮回、记忆泄漏、觉醒伏笔（留作未来"另类节目"选项，靠格式迭代不靠伏笔接力）；
- 兜帽人/雨夜都市/橱窗推镜等 S2 母题；旧版夸张广告词（主神开场为正经口吻）；
- 遇害闪前冷开场（观众第 0 秒不认识狄西，悬念钩子降级为主神介绍里的看点静帧）；
- 全片视频化、真人配音、多局混剪、单 POV 锁死。

## 9. 探索路线（4 条，2025 讨论记录）

1. **反应视频库 + chibi 人设**：**chibi 差分现在就做**（canon edit 转 Q 版）；**反应视频库缓行**——先等台词测试片段验证"静态差分+特效"够不够用，不够再只做"说话循环"（唇部微动+衣料轻摆，不逐句对嘴）。
2. **动漫风过场动画**：遇害场景过场动画**采纳为谋杀夜 L3 钱镜**（夜间黑暗卧室、剪影构图、不露凶手脸，黑暗容错率高；5–8s 无台词）——但已从冷开场撤下，归位故事本位（见 §8）。
3. **主神形象 + 正经节目介绍**：**采纳为开场**（黑影 + 正经介绍，取消夸张广告词）；纪律边界 = ≤25s、只说三件事、零规则讲解（防退化成说明书）。
4. **火山引擎 TTS**：**暂缓**（E1 用剪映音色），用户提供文档后再研究。

**附带决议**：抠图不走本地大模型（rembg 在 Python 3.15 无轮子、安装失败已放弃）；路线 = 剪辑软件人工抠图 或 `--transparent` 生成直出。
