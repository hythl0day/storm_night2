## 2. 资产 prompt 存档

### 2.1 街角电器行（clip B 参考图，待生成）

构图：画面右侧 = 街角电器行橱窗（电视墙）；左侧 = 另一条垂直马路向远处延伸；
下缘 = 与画面下边缘平行的街道（人行道 + 车行道，有行人与车辆）。

```
写实真人电影质感，现代中国大城市雨夜，21:9 横构图，街角路口。
画面右侧是街角一家老式电器行的橱窗：橱窗内整墙老式电视机堆叠成墙，
全部亮着蓝白色荧光与雪花噪点，玻璃上有细微雨痕与街灯反光；
画面左侧是另一条垂直的马路，向远处延伸、消失在雨雾与暖黄路灯光晕中；
画面下缘是一条与画面下边缘平行的街道：撑伞行人的黑色剪影走过人行道，
车辆在马路上拖出红白光轨。地面湿滑，水洼反射灯光。
光色真实克制：暖黄钠灯与电视荧光为主，无彩色霓虹。无人物正面、无可读文字、无水印。
```

## 4. 视频 prompt（三条独立 clip；均开音频，画外音由模型直出）

每条 clip 的广告旁白文案见 storyboard §1.1（已定稿），台词在 prompt 中用 `{}` 标记。
**画外音统一音质要求**（每条 prompt 都写）：男声、亢奋促销腔，听上去像从老式收音机/橱窗里的
电视机传出来——轻微失真、发闷、带电流底噪与轻微噼啪声。
环境声由模型自行发挥，只给方向（雨夜都市、人群雨声、电视电流噪）。
灭屏特效后期做（画面收缩成亮线→熄灭），不进视频生成。

## 5. 声音设计

- **广告旁白**：模型直出（本片段承担"Seedance 台词直出逐字稳定性"冒烟任务——若 `{}` 台词错字/
  漏字严重，退路 = 视频改无声版 + 后期配音，最终版仍为主神之声/用户本人录音）。音质统一要求：
  老式收音机/橱窗电视机质感（轻微失真、发闷、电流底噪），因为声源设定就是橱窗里的电视机。
- 环境声：高空风雨与城市低鸣 → 落地雨声 + 脚步声 → 街道雨声 + 电视电流底噪渐强 → 标题卡定格
  后"啪"一声灭屏电流断音 → 黑场静默。灭屏断音与灭屏特效一起后期做。
- BGM：无（负向控制已写进各 prompt）。

## 6. 已知待办 / 风险

- **API 约束（实测）**：Seedance 2.5 首尾帧模式不能与参考素材混用（HTTP 400：
  first/last frame content cannot be mixed with reference media content）。因此 clip A/B 全部只走
  参考素材模式（场景文字描述 or 场景 canon 作参考图），clip C 只用首尾帧。
- 台词直出冒烟：本片段三条 clip 的广告词即测试样本；逐条验收 `{ }` 内台词的逐字准确性。
- 镜头一坠落动感：v2 改纯文字驱动后重点验收坠落是否够"失重"、落地后镜头是否真的静止；
  若都市质感再次偏假，换 `modern-cityscape.png` 的文字口径（现代中国大城市、暖黄万家灯火）重抽。
- 广告海报：风格化 vs 写实六人脸，待用户拍板（§3）。
- clip C 的"最大电视屏幕 = 海报内容"靠文字描述 + 尾帧硬切，模型只能近似；若不可接受，
  备选方案是后期屏幕合成（海报图直接贴进画面）。
- 人群处理：全部雨伞剪影/背影/景深外模糊，规避 AI 视频人脸崩坏；兜帽人任何镜头不露五官。
- 成本闸：三条 clip 逐条生成、逐条向用户报价确认。
