## 4. 视频 prompt（两条 clip，尾帧衔接；均 --no-audio，声音全部后期）

**画幅一致性**：clip A 首帧 = `cyberpunk-cityscape.png`（21:9）；clip A 尾帧自动落盘 → clip B 首帧；
clip B 尾帧 = 标题卡——标题卡是 16:9，用前按 21:9 裁切上下黑边（纯黑背景零损失，PIL 一行搞定）。

### clip A：高空 → 雨巷 → 街角（约 14s）

参数：`--first-frame media/scenes/cyberpunk-cityscape.png --duration 14 --no-audio --resolution 720p`

```
@图片1 为开场画面（雨夜都市高空远景，两栋高楼在画面左右形成画框）。
写实真人电影质感，一镜到底连续运镜：
0-3s：高空夜景。镜头悬停在市中心两栋摩天高楼之间，远处多层高速立交匝道与过江高架桥上
车流拉出红白色光轨，近处霓虹招牌在雨雾中晕开，细雨在光里可见；
3-6s：镜头从高空急速垂直坠落，穿过楼间雨雾，失重下坠，落入地面一条漆黑小巷——
画面左右两侧是高耸砖墙与防火梯，正中巷道深黑，巷口外街道灯火通明；
6-11s：一个穿深炭色连帽长风衣的瘦削身影（面目完全隐在帽檐阴影中）从镜头背后走入画面，
向巷口走去；镜头低位跟随她的脚步前行，湿地水洼反射着巷口的霓虹；
11-14s：她走出巷口、向右转过街角，镜头跟上——街角一家老式电器行橱窗透出蓝白色荧光，
荧光先映在地面水洼里，再看到橱窗内整墙亮着雪花噪点的电视机。
（无配乐、无人声，电视只有画面闪烁。）不要字幕。
```

### clip B：橱窗 → 推屏 → 标题卡（约 8s）

参数：`--first-frame <clip A 尾帧> --last-frame <标题卡 21:9 裁切版> --ref <卡司广告海报> --duration 8 --no-audio --resolution 720p`

```
@图片1 为开场画面（街角电器行橱窗前，兜帽人背影）；@图片2 为结尾定格画面（节目标题卡）；
@图片3 为电视广告海报参考（六个风格化人物半身像与拿话筒的主持人黑色剪影）。
写实真人电影质感：
0-3s：兜帽人立在橱窗前，橱窗内整墙电视机播放着同样的广告画面，蓝白荧光映在她的兜帽轮廓上；
3-6s：镜头越过她的肩膀，推向橱窗正中最大的一台电视——屏幕上是图3的广告海报
（六个 AI 头像与主持人剪影）；
6-8s：电视屏幕占满整个画面，硬切到图2的标题卡，定格至结束。
（无配乐、无人声。）不要字幕。
```

## 5. 声音设计（全部后期）

- **广告旁白**（手写文案，见 storyboard §1.1）：贯穿两条 clip 连续念完，在标题卡定格时恰好收尾。
  最终版 = 主神之声（用户本人录音）；占位可用任意 TTS。视频生成不开音频，避免模型幻听人声与跨 clip 音色断裂。
- 环境声：高空风雨与城市低鸣 → 落地后雨声 + 脚步声（兜帽人入画时脚步先行）→ 橱窗段电视电流底噪渐强 →
  标题卡定格后"啪"一声灭屏电流断音 → 黑场静默。
- **灭屏特效后期做**（画面收缩成亮线→熄灭）：标题卡即 clip B 尾帧，灭屏不进视频生成。
