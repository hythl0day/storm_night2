# shot-1 · 冷开场片段（四镜头：高空坠落 → 混入人群 → 橱窗驻足 → 推镜入屏 → 标题卡）

> 对应 `screenwriting/s1-e1-storyboard.md` §1 冷开场。
> 镜头链：高空远景（两楼画框）垂直坠落进雨巷 → 兜帽人出巷混入人群 → 橱窗前驻足 →
> 推镜穿玻璃入屏（屏幕 = 卡司广告海报：六 AI 头像 + 主持人剪影）→ 屏幕占满 →
> 硬切标题卡定格 → 灭屏（后期特效）→ 黑场。
> 四镜各为一条独立 clip，可单独重抽；仅 clip 4 有帧衔接（首帧 = clip 3 尾帧，尾帧 = 标题卡）。
> 下一片段（shot-2）从"电视重新打开（雪花→影像）→ 狄西视角"开始，灭屏/亮屏即天然剪辑点。

## 4. 视频 prompt（四条独立 clip；均 --no-audio，声音全部后期）

每条 clip 对应一个镜头与一句完整广告旁白（文案见 storyboard §1.1），句子边界即剪切点。
仅 clip 4 有帧衔接要求（首帧 = clip 3 尾帧落盘，尾帧 = 标题卡——标题卡是 16:9，
用前按 21:9 裁切上下黑边，纯黑背景零损失，PIL 一行搞定）。

### clip 1（镜头一：高空远景 → 落入雨巷，约 5–6s）

参数：`--first-frame media/scenes/cyberpunk-cityscape.png --last-frame media/scenes/rainy-alley.png --duration 6 --no-audio --resolution 720p`

```
@图片1 为开场画面（雨夜都市高空远景，两栋高楼在画面左右形成画框），@图片2 为结尾画面（地面漆黑小巷）。
写实真人电影质感：镜头从高空两楼之间悬停开始，缓慢前推后急速垂直坠落，穿过楼间雨雾，
失重下坠，最终落进地面的漆黑小巷——画面左右两侧是高耸砖墙与防火梯，巷道深黑，
巷口外街道灯火通明。细雨在霓虹光里可见，远处高架车流拉出红白色光轨。
（无配乐、无人声。）不要字幕。
```

### clip 2（镜头二：出巷混入人群，约 5–6s）

```
@图片1 为场景（雨夜巷口：画面右侧漆黑巷口、左侧霓虹马路），@图片2 为人物参考
```

## 5. 声音设计（全部后期）

- **广告旁白**（已定稿，见 storyboard §1.1）：每镜一句完整句，句子边界即剪切点——
  clip 1 = 第 1 句、clip 2 = 第 2 句、clip 3 = 第 3 句、clip 4 = 第 4 句，
  第 4 句在标题卡定格时恰好收尾。最终版 = 主神之声（用户本人录音）；占位可用任意 TTS。
  视频生成不开音频，避免模型幻听人声与跨 clip 音色断裂。
- 环境声：高空风雨与城市低鸣 → 落地后雨声 + 脚步声（兜帽人入画时脚步先行）→ 人群雨声环境 →
  橱窗段电视电流底噪渐强 → 标题卡定格后"啪"一声灭屏电流断音 → 黑场静默。
- **灭屏特效后期做**（画面收缩成亮线→熄灭）：标题卡即 clip 4 尾帧，灭屏不进视频生成。
