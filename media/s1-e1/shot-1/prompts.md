## 2. 场景 canon：雨夜霓虹都市电器橱窗（Seedream 文生图）

```
写实真人电影质感，夜雨中的霓虹都市街道，电影宽幅构图。潮湿柏油路面反射着粉蓝与暖橙的霓虹灯牌，
细雨在光晕中可见，远处高楼没入雨雾。画面视觉重心是街角一家老式电器行的橱窗：橱窗内一整面墙
的电视机堆叠陈列，所有屏幕亮着、播放着同样的蓝白色闪烁光影（内容抽象不可辨），荧光洒在橱窗外
湿漉漉的人行道上。街道上行人稀少、撑伞匆匆。氛围：繁华但疏离，酷似现实世界的某座城市，却隐约
令人不安。影调：低饱和底色 + 高饱和霓虹点缀，雨夜空气感，浅景深。画面无文字、无水印。
```

备注：屏幕内容故意抽象（危机蒙太奇是成片后合成的事，见 storyboard §1 镜 2 备注）。

## 3. 兜帽人设定图（Seedream 文生图）

```
写实真人电影质感，角色设定参考图。同一个人物的三个视图并排：正面全身、侧面全身、背面全身；
深灰背景，影棚柔光。角色：一个穿深炭色长款连帽风衣的瘦削身影，兜帽压得很低，脸完全隐没在
帽檐阴影中——任何角度都看不清面目，只能感到"她"的轮廓偏纤细。衣着极简、无标志无配饰，
裤脚与靴面沾着雨水的湿痕。气质：安静、警觉、与周遭格格不入，像一个不属于这条街的人。
三个视图保持完全同一人物与服装。画面无文字、无水印。
```

备注：面目不清是设定本体（结局"天空"的回收谜面），任何版本都不得画出五官。身份留白，见 show-bible §4。

## 4. 标题卡（Seedream 抽卡，字形必须全对）

```
节目标题卡设计，纯黑背景。正中是手写毛笔书法大字「暴风夜·古堡惊魂」，银魂式标题卡美学：
笔触狂放有力、飞白明显、略带歪斜的不羁构图，朱红色为主、笔画边缘有金色飞白高光；
文字占据画面大部分空间，视觉冲击力强。除此之外画面空无一物。除标题文字外无其他文字、无水印。
```

备注：七个字（含间隔号）逐一核对，错一字即废片重抽；抽到合格为止。这是整条片子唯一不能交给
视频模型渲染的元素。

## 5. 分镜首帧（Seedream 多参考：场景 canon + 兜帽人）

```
参考图说明：图1 = 雨夜霓虹都市与电器橱窗场景；图2 = 兜帽人（深炭色连帽风衣，面目不可见）。
写实真人电影质感，夜雨霓虹都市街道，视角为街道人视高度的大远景：画面纵深尽头是图1的电器行
橱窗，电视墙蓝白荧光在雨雾中晕开；图2的兜帽人缩在画面下缘远处、沿街行走的背影，渺小孤独。
细雨、湿地反光、霓虹光晕。氛围压抑而华丽。画面无文字、无水印。
```

（生成时传参顺序与"图1/图2"指代一致。）

## 6. 视频主 prompt（Seedance 2.5，首帧 + 尾帧任务）

参数：`--first-frame frames/first-frame.png --last-frame frames/title-card.png --duration 18 --audio --resolution 720p`（首帧定比例；画幅在首帧生成时定，建议电影宽幅）。

```
@图片1 为开场画面（雨夜霓虹都市大远景，兜帽人背影在远处）；@图片2 为结尾定格画面（节目标题卡）。
写实真人电影质感，一个连续运镜，按时间推进：
0-6s：雨夜霓虹都市大远景，镜头缓缓下降并前推，雨丝在霓虹光晕中可见，都市喧嚣被雨声压住；
6-12s：镜头降到街道人视高度，跟随图1中的兜帽人背影沿街前行，她在电器行橱窗前驻足，
橱窗内电视墙蓝白荧光映在她的兜帽轮廓上；
12-15s：镜头越过她的肩膀推向橱窗正中最大的一台电视，屏幕光影逐渐占满整个画面；
15-18s：画面硬切到图2的标题卡并定格至结束。
声音：全程细雨环境音与潮湿街道氛围音；<远处雷声两次>；贯穿始终的亢奋促销腔男声广告旁白
{六个真实AI！场景互动、恐怖悬疑、身份推理、杀人游戏！没有剧本，没有替身——所有台词、
所有行动，全部由真实AI当场生成！《暴风夜·古堡惊魂》，本周目，谁能活着走出古堡？}
旁白在画面定格标题卡时恰好念完；(无配乐，只有雨声与城市底噪)。不要字幕。
```

**灭屏特效不进视频**：标题卡即尾帧，"电视关闭"（画面收缩成亮线→熄灭→黑场）在剪辑软件里
30 秒搞定，节奏还可逐帧调——不值得烧视频生成，也不让模型冒字形渲染的风险。
