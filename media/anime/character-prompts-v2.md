> v2 变更：生图引擎从 Seedream 切换到 GPT Image（`image-gen` skill，默认二次元画风已写入 skill 的 `style.md`，prompt 内不再重复画风与无文字约束）；版面从"大头+三视图"升级为**正式设定图**（全身多角度 + 常用表情 + 道具特写）；角色设计以真人版 prompt（`media/characters/prompts/`）为基准动漫化，并按 2025 讨论意见逐席调整。
> 生成方式（GPT_SIZE 用环境变量切横版；**全部角色统一纯 prompt 生成**，不用参考图——edit 模式会带入参考图的比例与画风，豆包已翻车一次）：
> ```bash
> GPT_SIZE=1536x1024 python .agents/skills/image-gen/scripts/image_gen.py gen "<下方单条 prompt 全文>" <席位id>-sheet media/anime/characters
> ```
> 已知坑（v2 教训）：
> - **黑底**：deepseek / doubao 首图均生成黑色背景（深发色角色似乎更容易触发），用 edit 模式一句"黑色背景替换为纯白色背景，其余不变"即可修复；验收时必查。
> - **未成年表述触发审核**：「16/17 岁 + 少女」会被内容审核 500 拒绝，统一用"约 18 岁 + 年轻女性"口径（canon 年龄已按此写）。
> - **道具命名会被文化联想劫持**：「卷轴」画成水墨画轴、「纸卷」画成厕纸/收银纸——要描述物理构成（"数张 A4 卷成筒、橡皮筋扎住"），不要只给物件名。

## 共用版面段（每条 prompt 开头相同，勿改）

```
角色设定参考图（character reference sheet），横向宽幅构图，纯白背景。布局：画面左侧为该角色的正面全身立绘（占比最大）；中间为同一角色的侧面全身与背面全身；右侧为同一角色的六个表情头像特写——通常、微笑、惊愕大喊、愤怒、慌张冷汗、得意坏笑，2×3 网格整齐排列；随身道具与服装细节的小特写格统一放在画面右下角（表情网格的正下方）。所有视图与表情都是完全同一角色、同一服装、同一妆发。
```

## 体格锚点原则（v1 教训）

体格是游戏机制属性，prompt 里光写"魁梧"会被美型默认吞掉，必须给可画出来的对比锚点：

- 魁梧（狄西/杰普特）：肩背宽阔呈倒三角、骨架明显大于常人数圈、头身比约 7.5；
- 健壮（克劳德/智谱）：克劳德 = 高挑（比同龄少女高半个头、腿长）；智谱 = 肩背厚实、站姿像一堵墙；
- 普通（格罗克/奇米）：标准少年少女体型；
- 瘦弱（杰米尼/豆包）：纤细娇小、手腕纤细。
