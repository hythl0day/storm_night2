# 8 人局补充规则

# 阵容

| 人数 | 平民 | 帮凶 | 杀手 | 主谋 |
| ---- | ---- | ---- | ---- | ---- |
| 8    | 5    | 1    | 1    | 1    |

## 情报

8 人局中：

帮凶和杀手互相知道身份、职业和道具，但不知道主谋的身份和道具。

主谋知道帮凶和杀手的身份、职业和道具。

## 幕后主谋

主谋和平民一样随机获得道具，也没有杀人的能力。判断谋杀条件，计算非反派人数时，需要计算他。他知道杀手和帮凶的身份、职业和道具。

开局前，主谋会得知目前场上没有出现的职业，并且可以选择扮演其中之一。主谋实际的技能和其声称的职业无关。并且因为主谋被动的存在，关于自身职业的发言并不会被看破是谎言。

主谋的技能：
【提线木偶】（主动，整个游戏两次）
效果：在投票阶段，强迫一个角色在投票时投给某个人。可以分成两次分别对两个人使用，也可以在一次投票时同时对两个人使用。受影响的角色正常投票。宣布结果时，所有人会得知票数被更改了，但不知道具体怎么改的。
【完美伪装】（被动，整个游戏两次）
效果：你的发言中关于职业、道具、技能和行踪的谎言，不会被【看破伪装】或【测谎仪】识破。这个技能在其他角色对主谋进行测谎时自动触发。自己能知道这个技能的次数何时耗尽。
【应急预案】（被动，整个游戏一次）
效果：免疫第一次针对自己的【谋杀】。当被杀手选择为目标时，谋杀会失败。效果等同于使用武器自卫或者使用急救包的效果。杀手无从分辨具体失败的原因。

# 胜利条件

主谋独赢：场上只剩下幕后主谋和另外一人（无论这个人是什么身份），则主谋独赢。反派和平民都算作失败。
平民胜利：投票淘汰所有杀手和帮凶（不含主谋）。平民获胜，反派失败。如果此时主谋未被淘汰，则主谋也算作失败。
反派胜利：杀死或投票淘汰所有平民。反派获胜，平民失败。如果此时主谋未被淘汰，则主谋和反派一同获胜。

# 房间

8 人局额外增加一个游戏室

| 房间   | 上锁 | 人数上限 |
| ------ | ---- | -------- |
| 游戏室 | 否   | 3        |

游戏室无法行凶，且游戏室视为永远保持不停电的状态。

# 开锁

在 8 人局中，如果在场三个人都同意开锁，可以不借助道具，暴力打开门锁或者保险箱的锁。

# 额外的开局准备步骤

幕后主谋确认杀手和帮凶的身份、职业和道具。
幕后主谋确认本局游戏没有出现的职业，并选择一个作为伪装。

# 指认阶段

在 8 人局中，从第二天开始，在公共发言前，增加一个指认阶段。

任何角色（包括杀手和帮凶）都可以对怀疑是主谋的人发动指控。指控前角色必须透露自身的职业和道具（不能撒谎）。如果失败，发起指控的角色本轮将会失去发言和投票的权力（第二天恢复）。如果成功，则主谋本人立即出局，游戏继续，指认成功者可以从两种情报中选择一种获取：

1. 【清点人数】: 目前场上还剩下 X 名反派（杀手+帮凶）。
2. 【锁定职业】: 剩下的反派中，有一 [XX 职业]。
3. 【窥探道具】: 剩下的反派中，拥有 [XX 道具]。

每个角色整局游戏只能指认一次。
