# 职业和道具

每个人开局时随机获得其职业和道具。

职业会给角色一些技能，通用技能是任何时候都可以使用的，而反派技能则是只有作为杀手或者帮凶才能使用。

在开局时每个人知道自己的职业和道具，但不知道其他人的。总共有十种职业和十四种道具(包含四种凶器)。因此某些职业和道具将从头到尾都不会出现。

角色可以将自己拥有的道具展示给其他人，也可以声称自己拥有某种道具或隐瞒道具情报。也可以将道具送给其他人。

道具只能从开局时获得，或者杀死别人且没有平民在场时获得，或者投票后由侦探分配出局和死亡者留下的未使用道具，此外没有获得道具的途径。

杀手必然会获得一件武器。

帮凶和平民会从杀手获得的武器之外剩下的道具种类中随机获得道具，平民也有可能获得武器（用于自卫），每个人的职业和道具都各不相同。

# 特殊身份

游戏会随机挑选 2 个人并给与特殊身份。

1 个人作为“帮凶”。帮凶自己不能杀人。当杀手被投票出局时，帮凶会立刻变成新的凶手。帮凶开局时必定获得四种武器其中之一。

1 个人作为“杀手”。游戏中只有杀手可以杀人，当房间中只有一个平民，并且满足道具或者身体条件时，他可以选择杀人。关于发动谋杀的具体条件，可以参考之后的游戏流程段落。杀手开局时必定获得四种武器其中之一。

帮凶和杀手共同被称作“反派”。互相知道对方的身份、职业和道具。

# 胜利条件

平民胜利：投票淘汰所有杀手和帮凶。平民获胜，反派失败。
反派胜利：杀死或投票淘汰所有平民。反派获胜，平民失败。

# 职业

不同的职业的技能有可能重复，某些道具上的效果也可能和某些技能效果相同。

## 医师

通用技能【现场调查】（主动，整个游戏两次）：
效果：当尸体被发现后的调查阶段，可以选择并获取一个关于案件的情报：

1. 武器伤痕：死者死于何种武器？
2. 死亡时间：死者死于哪个时间（自由活动时间或晚间休息时间）？
3. 尸体转移：尸体是否被转移？

反派技能【伪造痕迹】（主动，整个游戏一次）：
效果：在谋杀发生后，可以销毁物证。这使得【现场调查】技能除了「武器伤痕」之外的选项获得错误结果。

## 化学家

通用技能【现场调查】（主动，整个游戏两次）：
效果：当尸体被发现后的调查阶段，可以选择并获取一个关于案件的情报：

1. 武器伤痕：死者死于何种武器？
2. 死亡时间：死者死于哪个时间（自由活动时间或晚间休息时间）？
3. 尸体转移：尸体是否被转移？

反派技能【销毁证物】（主动，整个游戏一次）：
效果：在谋杀发生后，使【现场调查】技能除了「死亡时间」之外的选项获得错误结果。

## 运动员

通用技能【敏捷闪避】（被动，整个游戏一次）：
效果：当你成为谋杀的目标时，本次谋杀不成功。效果等同于道具「急救箱」。

反派技能 1【转移尸体】（主动，整个游戏一次）：
效果：在谋杀发生后，可以选择将尸体移动到另一个房间而不被发现。

反派技能 2【暴力破解】（主动，整个游戏一次）：
效果：在自由活动前使用，可以在当天制造一次停电。

反派技能 1【信号干扰】（主动，整个游戏一次）：
效果：在自由活动或晚间休息时，进入【监控室】后，可以指定一个之前的时间段的指定房间，添加、替换或者移除一个角色的进入房间的记录。

反派技能 2【暴力破解】（主动，整个游戏一次）：
效果：在自由活动前使用，可以在当天制造一次停电。

反派技能【伪造证物】（主动，整个游戏一次）：

反派技能【记忆植入】（主动，整个游戏一次）：

## 建筑师

通用技能【封闭空间】（主动，整个游戏一次）：
效果：在公开发言阶段，建筑师可以选择邀请某些人一同进入某个房间（也可以不邀请）。之后在自由活动时间，选择要进入的房间后，建筑师可以立即发动技能，将其大门“临时锁死”直到下一个自由活动时间。之后除了建筑师本人和其允许的人之外，其他人无法再进出此房间。拥有万能钥匙和「暴力破解」也无法进入。

反派技能【建造密道】：
（主动，整个游戏一次）
效果：在整局游戏开始前，建筑师可以事先选择一个非卧室的房间设置密道。在之后的任意一天的自由活动时间，他可以前往自己的卧室，并选择使用密道前往该房间，之后他可以在该房间进行谋杀、发动技能或道具，或者使用房间功能。然后再通过密道返回自己的卧室。此时建筑师被其他人视为从未离开自己的卧室（包括监控中也是如此）。密道使用一次后即视为被损坏。如果在密道出口所在房间有非反派角色。则密道使用失败，密道不会被发现，但之后也不能再使用。在建筑师使用密道时，自己的卧室视为等同于「封闭空间」，拥有万能钥匙和「暴力破解」也无法进入。

# 房间

对于上锁的房间，用任何方式开锁后，房间之后便永久保持打开的状态，其他人可以随时进入。

从第四天开始，除了卧室以外的所有门锁会自动打开。

| 房间   | 上锁               | 人数上限 | 环境凶器 |
| ------ | ------------------ | -------- | -------- |
| 地下室 | 是                 | 3        | 有       |
| 书房   | 否，但保险箱上锁。 | 3        | 有       |
| 监控室 | 否                 | 3        | 无       |
| 卧室   | 非本人需要开锁     | 2        | 无       |

## 地下室

地下室本身永远处于黑暗。当停电发生时，可以通过前往地下室并修复发电机来恢复供电。如果没能修复成功，之后将一直保持黑暗。

地下室视为永远保持黑暗状态。黑暗房间内无法进行交流，且杀手可以发动谋杀的非反派角色的限制放宽到二人。

地下室有环境凶器：电线。在这里无需道具，无需空手即可发动谋杀。但只能进行一次。之后将无法执行环境谋杀。

## 书房

书房有一个保险箱，书房本身没有上锁，但是保险箱上锁了。每次故事中，保险箱中会预先放置一个随机道具。可能是任意未出现的道具，包括武器。

书房有环境凶器：雕像。在这里无需道具，无需空手即可发动谋杀。但只能进行一次。之后将无法执行环境谋杀。

## 监控室

选择一个时间段以及两个指定场所（可以是某个公共房间或者所有人的卧室）查看。可以获得该时间段进入这两个场所的人员的记录。

只能在第二天或之后查看前一天的记录。只能在前一天发生了案件的情况下查看记录。

## 卧室

每个人有自己的卧室。自己可以自由进入，但其他人需要被邀请或者拥有开锁能力才可以进入。

但卧室即便被人开锁进入，下一个时间段也会立即恢复锁着的状态。

# 游戏流程

## 开局准备

帮凶、杀手互相知道身份、职业和道具。

拥有建筑师职业的角色，此时可以决定密道的位置。

拥有窃听器道具的角色，此时可以决定窃听器的位置。

保险箱中会随机出现一种当前角色未拥有的道具。并且可能是五种反派道具之一。

## 特殊规则

假如连续两个完整天（包含自由活动和晚间休息）没有发生谋杀（谋杀未遂也算作没有发生谋杀），则第三天早上平民直接获得胜利。

从第四天开始，除了卧室以外的所有门锁会自动打开。

## 行动顺序

第一天的行动顺序是完全随机的。之后每过一天，在一天开始的阶段，将第一个人放到末尾产生新的顺序。

故事中的角色始终按照顺序行动。包括侦探任命、赠送物品、发言都会以这个顺序进行。

顺序靠前的角色可以对之后的角色做出邀约、赠送等行动。

顺序靠后的角色则可以在自己行动前看到其他人的发言、选择的房间等情报。

决定顺序之后，如果发现人数不足（有人被谋杀），会立刻进入案件调查阶段。

## 案件调查

如果案件属于谋杀未遂，则仍旧会有调查的机会。不过调查员可以自行决定是否使用自己的技能。

此时案件所在的房间会直接被公布。如果案件所在的房间此时锁着，会被强行打开（但所有人会得知这个情报）。

如果有尸体，其职业如果此前未声明，此时会被公开。如果尸体身上有未被拿走的道具。会立刻被这一天的侦探收走，之后会在投票结束时进行分配。

此时拥有调查技能的角色可以主动申请做调查员。侦探也可以选择自己做调查员。

调查员可以选择对现场使用其技能或道具**之一**。并对所有人公布调查结果。当然他自己可能隐瞒调查结果。

当天的侦探单独查看监控，查看监控时可以根据之前对尸体调查获取的死亡时间来选择时间段。侦探需要选择一个时间段以及两个指定场所（可以是某个房间或者所有人的卧室）查看。可以获得该时间段进入这两个场所的人员的记录。之后侦探向所有人公布监控内容。但侦探也可能会公布虚假的情报。

如果一天之内发生了两次案件（第一次未遂），则第二次为主要案件。医生和化学家和鲁米诺只能用于第二次。但侦探查看监控时，可以额外选择第一个案件所在的时间段和场所。

## 公共发言

每个角色可以按顺序轮流发言一次。只有轮到自己才能说话。可以对即将进行的投票、目前的局面，以及之前的案件发表自己的看法；可以对自己或其他人的职业、道具、技能及是否是反派发表看法；可以对顺序更靠后的任意一个角色提问；可以回答之前其他人的质疑；可以赠送道具给任意位置的角色，对方可能拒绝。

侦探最后一个发言（第一天第一次公共发言时尚没有侦探）。

## 投票

从第四天开始，拥有武器的平民，可以在投票中未产生出局者的情况下，指认一个人作为凶手。假如指认成功，则平民直接获得胜利。如果指认的人是帮凶，也算作失败。指认失败的话，该名平民直接出局，但游戏仍将继续。

在第二天开始，公共发言后将会进入投票阶段。投票的同时，仍然可以附带简短的理由。

选出一个人作为反派的嫌疑人出局。在信息不足时可以选择不投票。如果一个人得票超过当前人数的一半（平票或票数不足算作本次无效），他将会出局，但出局之前他有一次最后的发言机会。

如果出局的人身上，或者之前发现的尸体上，有未使用的道具，此时将会由当天的侦探决定如何分配。侦探可以分配给自己。也可以选择当场销毁。（只能销毁没有主人的道具）。

**假如投票后只剩下一个平民，则直接算作反派获胜**。

## 侦探

从第二天开始，在投票结束后，新的顺序中，最靠前的人成为当天的侦探。

## 自由活动

从第二天开始，如果持有停电的技能和道具，可以在此时选择触发。但玩家直到选择并进入房间之后才会得知停电发生。

所有人按照顺序行动，无法看到其他人做出的选择。

每个人选择任意一个房间并准备进入（锁着的房间也可以选择）。房间列表包括：书房、监控室、地下室（锁着）、自己的卧室（锁着，除了自己之外，非邀请不能进，最多两个人）。侦探选择的房间会立即公开给所有人。其他人则不会公开。选择房间的同时，可以选择向顺序更靠后的任意一个或多个角色发出一同进入的邀请。顺序靠后的人，如果选择的目标房间已经达到了人数限制，会在此时得知房间已满，他需要重新选择其他房间。即便是是目前锁着的房间，也要遵守人数上限。所有人的房间选择和邀请结算完毕后，每个人才会见到和自己选择了相同房间的人。

如果是上锁的房间，且拥有对应技能或者道具，此时可以开锁。如果同一个房间有多个人拥有此技能。顺序更靠前的角色先使用其技能或道具。开锁的事情会被同样选择了这个房间的其他人看到。但其他人除了看到开锁的人之外，并不知道开锁的具体方法。

如果此前有人触发了停电。将会在此时发生效果。进入的房间是地下室时，将会视为发生了停电。除非有人在进入房间时使用了手电筒。

此时如果房间中非反派角色的总数满足条件时，杀手可以在此时决定是否谋杀，以及谋杀的目标和方式。如果谋杀成功，将会跳过之后的房间交谈阶段。

此时房间内的人可以进行自由交谈，但有时间限制。如果触发了停电事件，则跳过交谈阶段。

房间内行动，可以选择使用房间设施，例如查看监控或修复发电机。也可以尝试打开保险箱获得其中的物品。如果此前没有触发停电，这些行为都会被同在一个房间的人看到。相对的，如果发生了停电，则没人知道是谁进行了行动。

## 谋杀

如果在场只有一个非反派角色，杀手可以在此时选择发动谋杀。如果选择放弃，则直到下一个时间阶段，不能再次选择谋杀。

环境谋杀：如果当前地点有可以利用的环境，例如书房或者地下室，则可以使用书房的雕像，或者地下室的电线，完成一次谋杀，此时对方无法使用武器自卫。

道具谋杀：如果使用了凶器，则无论体格、性别，即可杀人。但如果对象身上拥有可以对凶器自卫的对应武器，谋杀会失败。此时凶手不会被发现身份，但目标会知道有人袭击。

空手谋杀：不使用任何道具。此时对方无法使用武器自卫（但仍可用道具或技能躲避）。除了谋杀的基本要求（只有一个非反派角色）空手谋杀必须满足下列条件**之一**：

1. 有帮凶在场。
2. 杀手自身体格数值大于或等于对方。
3. 自身是男性而对方是女性。

如果此时发生了「停电」事件，或者发动了魔术师技能，则谋杀时在场非反派角色的数量放宽到二人。且空手谋杀没有任何限制。

用任何方式谋杀都会留下痕迹，用于「现场调查」技能的判断。

行凶时，如果对方有对应的技能或者自卫道具，谋杀会失败。杀手无从分辨具体失败的原因。被谋杀的目标会自动使用对应的道具或者技能。被谋杀的目标以及在场的其他平民只是会得知此人被袭击，但并不知道是谁发动的。

谋杀成功后：

如果尸体身上有未使用的道具，则杀手获得该道具。

杀手和帮凶可以选择是否发动自身反派技能或使用道具掩盖踪迹或转移尸体。

但房间内有其他非反派角色，则杀手不能拿走道具，杀手和帮凶也不能发动反派技能和使用相关道具。

## 晚间休息

如果自由时间发生了停电。晚间休息时，卧室视为拥有紧急照明。但其他房间，以及第二天的自由时间仍会保持停电。

所有人按照顺序行动，无法看到其他人做出的选择。

可以向一个行动顺序在自己之后的玩家发出留宿邀请。但只有当轮到收到邀请的人行动，并且同意留宿邀请，并且发出邀请的人自己的房间没有被杀手提前进入，他才可以成功进入邀请人的卧室。

如果自身拥有开锁能力或者对应房间已经开锁，可以选择不进入自己的卧室，而是进入书房、地下室和监控室。执行打开保险箱、破坏发电机和破坏监控的行动。夜晚的房间，除了卧室之外，只能进入 1 个角色。顺序靠前的人会导致靠后的人进入失败，只能重新选择。

杀手如果之前的自由活动时间没有选择发动谋杀，或者没有谋杀成功。可以在晚间再次尝试。

杀手可以进入有 1 个平民的房间。杀手已经进入的房间，平民也可以再次进入 1 人。如果杀手有开锁能力，可以尝试进入某个人的卧室，如果该卧室已经有两个人。则会无法进入，并算作谋杀失败。

对于卧室而言，靠前的人邀请他人到自己卧室后，靠后的杀手也无法再谋杀。但反过来也一样，靠前的人选择了过夜，靠后的人就无法进行房间行动。靠前的杀手已经进入房间后，后面的被邀请的人也无法再进入。行动失败的人会得知房间已经被占据但并不知道具体的人。和白天的自由行动时间不同，夜晚的选择失败后，会默认返回自己卧室。
