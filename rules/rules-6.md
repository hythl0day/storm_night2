# 暴风夜 · 6 人局规则书 v3

> v3 修订：会客室成为自由活动可选房间（永不黑暗/不设监控/夜间不开放）；白天卧室清场禁入；
> 【建造密道】改为夜间使用、出口三功能房任选、进入条件同谋杀人数条件、失败不损毁；
> 「窃听器」收听改为晚间在卧室进行、次数增为 2 次；新增同宿密谈（留宿两人睡前一轮）；
> 【武装指认】取消第 4 天起的限制，首次投票起、投票未产生出局者即可指认（每次投票至多一次）；
> 【破门而入】可用于晚间休息；侦探改为只在已有谋杀案件时指定（无侦探日道具分配平票即销毁）。

> 本规则书对全体玩家公开。未知的只有：每个人的身份、职业、道具，以及私密事件的经过。
> 你可以就任何事实撒谎，但你声明的"动作"必须合法——非法动作会被主持人直接驳回。
> 文中【】内为技能名，「」内为道具名。

---

## 1. 阵容与身份

本局共 6 名玩家。**角色表（每人的名字 / 性别 / 体格 / 国籍）由主持人在开局时创建，并全员公布**；本规则书不含固定角色表。

身份分配（随机，互不知晓）：**平民 ×4、帮凶 ×1、杀手 ×1**。

- 杀手与帮凶合称"反派"，开局时互相知道对方的身份、职业、道具。
- 杀手是唯一拥有杀人能力的人；帮凶不能杀人。
- 杀手被投票出局时，帮凶立即继任为杀手（仅私下通知本人，不公开公告）。
- 体格数值用于空手谋杀判定（见 §7.6）。

## 2. 开局分配

- 每人随机获得 **1 个职业**（9 选 6，不重复）和 **1 个道具**（14 选 6，不重复）。本局未出现的职业与道具对所有人保密——任何人都不能确定某个职业或道具是否在本局中。
- 杀手、帮凶必定各获得 1 件凶器（消音手枪 / 刀 / 棒球棍 / 毒药 之一，互不重复）；平民从剩余道具池中随机获得（可能获得武器，仅可用于自卫）。
- 书房保险箱内固定放置 1 件凶器（从本局未分配给反派的两件凶器中随机）。**开局时主持人全员公告此事（主人留下的字条），但不公布具体是哪件凶器。**
- 开局准备阶段：反派互认；反派建筑师获知密道网的存在（见 §3【建造密道】，无需选定出口）；窃听器持有者决定放置位置。

## 3. 职业一览（9 种）

技能分"通用"（任何人都可用）与"反派"（仅杀手/帮凶可用）。次数均为整局限定。

**医师**
- 通用【现场调查】×2：见 §4 词条。
- 反派【伪造痕迹】×1：某起谋杀发生后，使该案件所有【现场调查】/「鲁米诺试剂」的结果中，除「武器伤痕」外的选项全部得到错误结果。

**化学家**
- 通用【现场调查】×2。
- 反派【销毁证物】×1：同上，但仅「死亡时间」保持正确。

**运动员**
- 通用【敏捷闪避】×1（被动）：你成为谋杀目标时自动触发，本次谋杀失败。效果等同「急救箱」（可以防御毒药）。
- 反派【转移尸体】×1：某起谋杀成功后，将尸体移动到另一个房间而不被发现。
- 反派【暴力破解】×1：见 §4 词条。

**黑客**
- 通用【破门而入】×1：自由活动或晚间休息时间，打开一扇上锁的房门或保险箱。
- 反派【信号干扰】×1：见 §4 词条。
- 反派【暴力破解】×1。

**犯罪侧写师**
- 通用【犯罪侧写】×1：案件调查阶段使用，获知杀手本人的一项特征：性别 / 国籍 / 体格（仅报「强壮」或「普通」，由主持人按体格数值判定）。对延时装置与舞台魔术造成的案件，结论指向设置者/表演者本人。
- 反派【伪造证物】×1：某起谋杀发生后，使该案件所有【现场调查】/「鲁米诺试剂」的结果中，除「尸体转移」外的选项全部得到错误结果。

**心理医生**
- 通用【看破伪装】×2：公共发言阶段、自己发言之前使用，获知指定一名玩家**此前发言中关于"职业、道具、技能、行踪"的声明**是否含有谎言（行踪 = 声称去过的房间与做过的房间行为）。无法验证"我是不是凶手/反派"之类的声明。
- 反派【记忆植入】×1：投票阶段，强迫一名玩家投给你指定的人。结果公布时，所有人只会得知"票数被更改过"，不知道细节。

**建筑师**
- 通用【封闭空间】×1：公共发言阶段可声明邀请某些人（也可不邀请）随你进入某房间；自由活动时间你进入目标房间后可立即发动，将该房间大门临时锁死至下一个自由活动时间，除你与你许可的人外任何人无法进出（万能钥匙与【暴力破解】也无效；不能对会客室使用——开放大厅没有可锁的大门）。
- 反派【建造密道】×1：开局前你确认古堡中存在一条密道网（无需指定出口）。任意一天的**晚间休息**，你可以选择经密道前往**书房/监控室/地下室**之一（不能通往卧室）——这即是你当夜的行动，与夜袭/夜间房间行动互斥，但不受夜间房间 1 人名额限制。进入条件与谋杀的人数条件相同：出口房间当时在场非反派角色 ≤1（黑暗房间 ≤2）；不满足则当晚无法使用（密道保留、不暴露）。成功进入时，监控与众人眼中你当晚一直在自己卧室（不留进入记录）；你可以在该房间正常行动（房间设施/技能/道具；若你是杀手，可发动谋杀——消耗当夜谋杀机会，受 §7.6 全部条件约束）。成功使用一次后密道损毁；整局至多成功一次。停电不影响密道使用；出口房间的谋杀条件按当时明/暗状态判定。

**机械师**
- 通用【破门而入】×1。
- 反派【延时装置】×1：自由活动时间在任一非卧室房间（会客室/书房/监控室/地下室）秘密设置装置。之后任意时刻，若该房间处于"只有一名非反派角色单独进入"的状态，装置自动触发将其击杀（无需你在场，不占用你当阶段的谋杀机会）。无法被【敏捷闪避】/「急救箱」防御。该案件的武器伤痕结论为"机关"。装置未触发前一直有效，触发或被拆除前你不得再次设置。整局限设置一次。

**魔术师**
- 通用【看破伪装】×2（同心理医生）。
- 反派【舞台魔术】×1：在任意人数的非反派角色在场时，可空手完成谋杀，无法被【敏捷闪避】/「急救箱」防御。所有目击者得到的结论是：**"这是谋杀，凶手就在当时在场的人之中"**——不指向任何具体的人，你本人也不被排除。该案件的武器伤痕结论为"空手"，犯罪侧写正常指向你本人。

**（说明）**：所有职业的反派当杀手时，空手谋杀均须满足 §7.6 的体格/性别条件——魔术师与机械师不再有额外限制。

## 4. 道具一览（14 种）

除标注外，每个道具限用 1 次，用后销毁。道具可在"交换环节"赠送给他人（对方可拒绝）。平民不能把武器用作凶器，不能使用反派道具。

| 道具 | 次数 | 效果 |
| ---- | ---- | ---- |
| 消音手枪 | 1 | 凶器。持枪者面对刀/棒球棍的袭击时可自卫 |
| 刀 | 1 | 凶器。持刀者面对棒球棍的袭击时可自卫 |
| 棒球棍 | 1 | 凶器。持棍者面对刀的袭击时可自卫 |
| 急救箱 | 1 | 面对任何凶器（含毒药、环境凶器）可自卫；也可用于同在现场的其他人 |
| 手电筒 | 2 | 进入地下室或遭遇停电时可选择使用：本次你所在房间不视为黑暗 |
| 万能钥匙 | 2 | 打开一扇上锁的房门或保险箱 |
| 测谎仪 | 1 | 等同【看破伪装】 |
| 鲁米诺试剂 | 1 | 等同【现场调查】 |
| 窃听器 | 2（收听） | 开局前秘密放置于一个非卧室房间（含会客室——它是唯一能监视会客室的手段）。之后任意一天**晚间休息**，你身处自己卧室时可收听一次：获得当天自由活动时段该房间内的全部交谈记录 |

| 反派道具 | 次数 | 效果 |
| ---- | ---- | ---- |
| 毒药 | 1 | 凶器。仅「急救箱」/【敏捷闪避】可防御，任何武器无法自卫；毒药不能用于自卫 |
| 螺丝起子 | 1 | 等同【暴力破解】 |
| 可疑的粉末 | 1 | 等同【伪造证物】 |
| 裹尸袋 | 1 | 等同【转移尸体】 |
| 病毒 U 盘 | 1 | 等同【信号干扰】 |

技能词条：

- 【现场调查】：案件调查阶段对某起案件使用，从三项中任选一项获知真实结论：① 武器伤痕（利器 / 钝器 / 枪 / 毒或药物 / 空手 / 机关 / 雕像 / 电线）；② 死亡时间（哪个时间阶段）；③ 尸体转移（是否被移动过）。
- 【暴力破解】：在自由活动阶段开始前秘密声明，当天自由活动时间发生停电（见 §7.5）。
- 【信号干扰】：自由活动或晚间休息进入监控室后使用，指定"某个时间段 × 某个场所"的监控记录，添加、替换或移除**其中一条**进入记录（一次只能改动一条）。篡改后的记录对所有人（含公开宣读）生效。

## 5. 房间

| 房间 | 锁 | 人数上限 | 环境凶器 |
| ---- | ---- | ---- | ---- |
| 会客室 | 无锁 | 不限 | 无 |
| 书房 | 无锁；保险箱上锁 | 3 | 雕像 |
| 监控室 | 无锁 | 3 | 无 |
| 地下室 | 上锁；永久黑暗 | 3 | 电线 |
| 卧室（每人一间） | 白天不开放；夜间非本人需开锁或被邀请 | 2 | 无 |

- 开锁手段：【破门而入】/「万能钥匙」。房门（含保险箱）被打开后永久保持开启；**例外**：卧室被他人开锁进入后，下一个时间阶段恢复上锁。
- 第 4 天起，除卧室外所有门锁自动打开。
- **会客室**：白天会议场所，自由活动时间同样开放。壁炉长明——**永不黑暗**（停电也不受影响），内谈可自由交谈。夜间不开放。会客室**不设监控**；它是开放大厅，没有可锁的大门，【封闭空间】不能对会客室使用。
- **卧室白天清场**：白天会议结束（进入自由活动）后，卧室一律上锁，任何人（含本人）不得进入或逗留，直至晚间休息。
- **地下室**：永久黑暗。黑暗房间内无法进行交谈；其中的谋杀，非反派人数限制放宽至 ≤2（见 §7.6）。停电后，任何人可前往地下室修复发电机，成功则供电恢复（停电结束）。
- **监控室**：进入可查看监控记录（见 §7.2 与 §9）。
- **书房保险箱**：打开者获得其中道具（被同房者看见开保险箱的行为，但看不见获得了什么）。
- **环境凶器**：书房雕像 / 地下室电线。杀手在场满足谋杀条件时可使用，不限次数；目标无法用武器自卫（急救箱/闪避仍可防御）。武器伤痕结论为"雕像"/"电线"——会直接暴露案发房间。

## 6. 时间轴与行动顺序

一天 = 三个时间阶段：

| 阶段 | 位置 | 可否行凶 |
| ---- | ---- | ---- |
| 案件调查 + 公共发言 + 投票（合称"白天会议"） | 会客室（全员） | 不可 |
| 自由活动 | 会客室 / 书房 / 监控室 / 地下室（白天卧室清场） | 可 |
| 晚间休息 | 自己卧室（上锁）或夜间行动 | 可 |

- **第 1 天全天禁止谋杀**；第 1 天没有投票；侦探只在有案件时存在（见 §7.4）。
- 行动顺序：第 1 天完全随机；之后每天开始时，将顺序首位移到最后。邀约、赠送、发言、夜间行动等一切结算均按此顺序。
- 顺序靠后者在行动前可以看到顺序靠前者的公开选择（如房间选择的结果性信息、发言内容）。

## 7. 阶段细则

### 7.1 清晨与案件调查

- 每天清晨，主持人公告：上一日（自由活动与晚间）发生的全部**死亡**及案发房间。谋杀未遂也会公告（"某人遇袭但幸存"，不公布袭击者与方式）。
- 若案发房间当时上锁，强制打开并公告此事实。
- 死者的职业若从未公开过，此时公开（身份不公开——只有投票出局才揭示身份）。
- **监控公开**：主持人公开宣读原始监控记录：案发时间段 × 两个场所（案发房间 + 死者卧室）的进入者名单。监控只记录"进入"，不记录"离开"。
- **调查自荐**：任何持有【现场调查】/「鲁米诺试剂」/【犯罪侧写】的角色均可申请调查，各自选定一项内容；结果**私下告知本人**，由本人决定是否公布、隐瞒或撒谎。
- 一天内多起案件时，每起案件都可被调查；同一起案件同一调查项可被多人重复验证。
- 侦探（第 2 天起存在）额外特权：可再指定一个时间段 × 两个场所查看监控，并负责向大家转述（侦探可以撒谎——这是侦探唯一的信息特权）。
- 尸体上未被拿走的未使用道具此时被收走封存，投票结束后处理（见 §7.3）。

### 7.2 公共发言

- 按行动顺序每人发言一次（侦探最后发言）。
- 发言内容不限：分析、指控、质疑、声明、辩护均可；可向顺序靠后者提问。
- 发言结束后进入**交换环节**：按顺序，每人可发起一次道具赠送，对方可拒绝。

### 7.3 投票与出局

- 第 2 天起，每天公共发言后投票。可弃权。得票**超过**当前存活人数一半者出局（平票、未过半则本次无人出局）。
- 出局者先发表**遗言**（可以撒谎），随后主持人公布其**身份（平民/帮凶/杀手）与职业**。
- 若出局者是杀手：私下通知帮凶继任杀手。
- **道具分配**：出局者与当天尸体上封存的未使用道具，经公开讨论后投票决定归属（侦探在平票时有裁决权；无侦探的日子平票即销毁）；也可投票销毁（只能销毁当前无主的道具）。分配到的道具次日起可用。
- **若投票后存活的平民只剩 1 人，反派立即获胜。**
- **武装指认**（第 2 天起，即首次投票起）：一次投票未产生出局者时，持有武器（消音手枪/刀/棒球棍）的平民可指认某人为杀手。指认正确 → 平民立即获胜；指认为帮凶或平民 → 指认者直接出局，游戏继续。每次投票至多接受一次指认（按行动顺序，先声明者优先）。

### 7.4 侦探

- **侦探只在有案可查时存在**：每天开始时，若已发生任何谋杀案件（无论哪天发生，未遂不算），新行动顺序的首位成为当天侦探；没有案件的日子不设侦探（第 1 天必然没有）。
- 职权：① 调查阶段的额外监控查询与转述（见 7.1）；② 道具分配平票裁决（无侦探的日子平票即销毁）；③ 公共发言最后发言；④ 自由活动时间，侦探选择的房间立即对所有人公开。
- 侦探不是调查垄断者：任何有调查能力的人都能自查（见 7.1）。

### 7.5 自由活动

1. **停电声明**：持有【暴力破解】/「螺丝起子」者，可在本阶段开始前秘密声明发动，当天自由活动时间停电（进入房间后才向众人公布）。
2. **选择房间**：所有人按顺序秘密选择去向：**会客室 / 书房 / 监控室 / 地下室**（白天卧室一律清场，不可选择）。可同时向顺序靠后者发出同入邀请（对方可选择更改自己的目的地）。若选定房间已满，则立即得知并改选。**不作选择或选择无效者默认滞留会客室。**侦探的选择立即公开。
3. **开锁**：房间上锁且有开锁手段者可开锁（多人同时具备时，顺序靠前者先）。同房者只看到"谁打开了门"，不知道具体方式。
4. **停电结算**：停电生效时，除卧室与会客室外所有房间视为黑暗（地下室恒为黑暗）。「手电筒」持有者可声明使用，其所在房间本次不视为黑暗。
5. **谋杀判定**：见 §7.6。谋杀成功则跳过该房间的交谈。
6. **房间交谈**：同房者可自由交谈，每人按行动顺序发言一次，后发言者能看到本房间先发言者的发言（含会客室；黑暗房间内无法交谈）。
7. **房间行动**：使用房间设施（查监控 / 修发电机 / 开保险箱等）。非黑暗时，这些行为会被同房者看见；黑暗中则无人知道是谁做的。

### 7.6 谋杀判定

**发动条件**（杀手主动决定，每阶段一次机会，放弃则本阶段不能再杀）：

- 在场非反派角色数：正常 ≤1；黑暗房间 ≤2。
- **空手谋杀**还须满足以下**之一**：① 帮凶在场；② 本人体格 ≥ 目标体格；③ 本人男、目标女；④（夜间限定）在目标自己的卧室偷袭，体格门槛放宽为 ≥ 目标体格 −1。黑暗房间中空手谋杀无任何附加条件。
- **凶器谋杀**：无条件（毒药只能由杀手使用）。
- **环境谋杀**（雕像/电线）：无条件。

**自卫判定**：目标持有能克制该凶器的武器 / 「急救箱」/【敏捷闪避】时，谋杀自动失败（自动触发，无需目标声明）。克制关系：枪←无效；枪防御刀与棍；刀防御棍；棍防御刀；急救箱与敏捷闪避防御一切（含毒药、环境凶器）；毒药只被急救箱/敏捷闪避防御。延时装置与舞台魔术无法被任何方式防御。

**失败后果**：目标与在场者得知"有人遇袭/此人遇袭"，但不知道袭击者是谁；杀手也无法分辨失败原因（是武器、急救箱还是技能）。未遂计入"无杀倒计时"（见 §8）。

**成功后果**：

- 若现场没有其他非反派角色：杀手获得尸体上全部未使用道具；杀手/帮凶可发动毁证类反派技能或道具（伪造痕迹/销毁证物/伪造证物/转移尸体等）。
- 若现场有其他非反派角色：不能拿道具、不能毁证。
- 死亡公告在该阶段结束时发出（见 7.1）。

### 7.7 晚间休息

- 若白天发生停电：晚间卧室有紧急照明（不视为黑暗）；其他房间仍黑暗（会客室夜间不开放）；若发电机未修复，停电延续到次日。
- 按顺序行动，互相不可见选择：
  - **回房休息**：默认回自己卧室过夜。身处自己卧室且窃听器已放置者，可收听一次（见 §4「窃听器」）。
  - **留宿邀请**：可邀请一名顺序在自己之后的玩家来自己卧室过夜。对方行动时若同意，且你的卧室未被杀手提前进入，则对方进入（卧室满 2 人后他人无法进入）。
  - **夜间房间行动**：拥有开锁手段或目标房间已开锁者，可不回卧室，改为进入书房/监控室/地下室之一执行一项行动（开保险箱、查监控、修发电机）。每个夜间房间只能进入 1 人：顺序冲突时靠后者进入失败。
  - **密道**：反派建筑师可经密道前往书房/监控室/地下室之一（见 §3【建造密道】，不受夜间房间 1 人名额限制）。
  - **杀手夜袭**：若自由活动未发动谋杀或未成功，杀手可在夜间再尝试一次。可进入有且仅有 1 名平民的房间；有开锁手段时可尝试进入某卧室——若该卧室已有 2 人则无法进入（记为谋杀失败一次）。
- 结算顺序细则：顺序靠前者邀请他人成功后，靠后的杀手无法再袭击该卧室；靠前者选择夜间房间行动后，靠后者同房间行动失败；杀手已进入某卧室后，被邀请者无法再进入。行动失败者默认返回自己卧室，仅得知"无法进入"，不知原因。
- **同宿密谈**：归宿结算后，通过留宿邀请同处一间卧室的两人，睡前可密谈一轮——按行动顺序各发言一次，后发言者能看到先发言者的话；内容只有彼此知道。被杀手夜袭进入的卧室不交谈。
- **深夜谋杀**：密谈结束后进入深夜。无论杀手如何与他人同处一室（夜袭进入 / 受邀留宿），只要满足 §7.6 条件就有一次谋杀判定机会；经密道进入功能房的杀手也在此刻判定。

## 8. 胜负条件

- **平民胜利**：投票淘汰杀手与帮凶（全部）；或武装指认杀手成功；或无杀倒计时完成（见下）。
- **反派胜利**：所有平民死亡或被投票出局（含"投票后只剩 1 名平民"的即时判定）。
- **无杀倒计时**：自首起谋杀行为（含未遂）发生后起算，若之后**连续两个完整天**（自由活动+晚间休息）没有任何谋杀行为，则第三天清晨平民直接获胜。谋杀未遂同样重置倒计时。
- **主神胜利**：第 5 天晚间休息结束时仍无阵营获胜（包括从未发生任何谋杀行为的情况），则**全员失败，主神获胜**。

## 9. 关键裁定速查

1. **监控**：只记录"某时间段谁进入了某场所"，不记录离开、不记录房间内行为。监控覆盖书房/监控室/地下室与各卧室门口；**会客室不设监控**。记录可被【信号干扰】/「病毒 U 盘」篡改（一次一条），篡改对所有人可见的宣读结果生效。经密道者的进入不留记录（记录上此人一直在自己卧室）。
2. **看破伪装**：只验证"职业、道具、技能、行踪"四类声明是否为谎言。"我是清白的"等声明不在验证范围内。
3. **死亡公告**：谋杀（含未遂）在其发生的阶段结束时立即公告"谁死了/谁遇袭 + 案发房间"，死因细节留待次日清晨的调查阶段。
4. **身份揭示**：只在**投票出局**时发生（遗言在揭示之前）；死亡不揭示身份，只揭示职业（若此前未公开）。
5. **黑暗**：地下室永久黑暗；会客室永不黑暗；停电期间除卧室与会客室外全部黑暗；黑暗 = 无法交谈 + 谋杀条件放宽 + 房间内行为不可见。
6. **道具**：默认限 1 次（手电筒、万能钥匙、窃听器收听为 2 次）；转手不影响剩余次数；被收走封存的道具当天投票后才分配、次日可用。
7. **次数与合法性**：主持人掌握全部技能/道具剩余次数；声明使用不存在的手段、次数耗尽的技能或不满足条件的动作，会被直接驳回（其他人不会知道你被驳回过）。
