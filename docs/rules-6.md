# 暴风夜 · 6 人局规则书 v4.0

> 你在古堡中醒来，失去了记忆。大厅的桌上放着这本册子。所有人都能看到这本册子的内容。
> 这本册子由主神留下——他是这场游戏的设立者与裁决者；你可以就任何事实撒谎，但你声明的"动作"必须合法——非法动作会被主神直接驳回（私下告知你，可当场重新声明一次）。
> 每个阶段，主神都会给你一份"当前合法动作"的菜单；菜单之外的事你做不到。遇到册子上没写的事，主神会临场解释。
> 你听到的每句话都可能是谎言；主神发布的每条公告都是真的。

## 1. 阵容与身份

本局共 6 名玩家。**角色表（每人的名字 / 性别 / 体格 / 国籍）由主神在开局时创建，并全员公布**；本规则书不含固定角色表。

身份分配（随机，互不知晓）：**平民 ×4、杀手 ×2**。

- 两名杀手合称"反派"，开局时互相知道对方的身份、职业、道具。
- 两名杀手都拥有完整的**主动谋杀权**（§7.6）：每天自由活动与晚间休息各有一个谋杀窗口，全队共享每个窗口一次尝试、每天至多一起成功谋杀。
- 杀手出局不触发任何继任——剩下的杀手照常行动。
- 体格数值用于空手谋杀判定（见 §7.6）。

## 2. 开局分配

- 每人随机获得 **1 个职业**（8 选 6，不重复）。本局未出现的职业与道具对所有人保密——任何人都不能确定某个职业或道具是否在本局中（例外：万能钥匙、螺丝起子、桌上凶器与四件凶器的去向结构是公开规则，见下）。
- 道具按道具池分配：
  - **杀手（2 人）**：各得凶器×1——两件凶器为 刀 / 棒球棍 / 不明药剂 中互不重复的两件（「左轮手枪」不进反派道具池，见下）。其中随机一名杀手另得「万能钥匙」（反派开锁手段固定在线）；另一名杀手另得随机 1 件反派道具（可疑的粉末/木马程序U盘 之一）。
  - **平民（4 人）**：其中随机 1 人固定获得「螺丝起子」；其余 3 人从「通用道具池（急救箱/手电筒/测谎仪/鲁米诺试剂/窃听器，5 件）+ 反派道具中未被分出的那件」共 6 件中各随机抽 1 件。平民拿到武器仅可用于自卫；拿到不明药剂则可当救命药（见 §4）；平民拿到「可疑的粉末」只能用于正常调查，不能篡改（见 §3.1【现场调查】）。
- **桌上凶器**：会客室桌上固定放有一把「左轮手枪」（主人的收藏，开局全员公告）。白天任何人不能拿取（开放大厅、众目睽睽）；第 1 天侦探竞选产生侦探后归侦探持有（§7.4）；若无人持有，夜间独处会客室者可取走（§5、§7.7）。**四凶器仍然全部入场**：反派 2 件 + 桌上 1 件 + 保险箱或平民 1 件。
- 书房保险箱内放置 1 件道具：从**未被分配的剩余凶器 + 剩余反派道具**中随机（即可能是凶器也可能是反派道具；若抽中反派道具，剩余的那件凶器改由随机一名平民获得）。**开局时主神全员公告保险箱的具体内容（主人留下的字条）。**
- 开局准备阶段：反派互认。窃听器不在此阶段放置，须由持有者后续进入目标房间后设置（见 §4）。

## 3. 职业一览（8 种）

技能分"通用"（任何人都可用）与"反派"（仅杀手可用）。次数均为整局限定。反派职业技能造成的击杀归属于发动者本人（杀手线索同样指向发动者，见 §3.1【现场调查】词条）。

**医师**
- 通用【现场调查】×2：见 §3.1 词条。
- 反派【药理学】×1：药毒两用，效果完全等同「不明药剂」——**可杀人**：谋杀窗口对目标使用（凶器判定，满足人数条件即可，不要求体格/性别/同伙；可被「急救箱」/【敏捷闪避】/【药理学】/药用的「不明药剂」防御；武器伤痕为"毒或药物"；占用本窗口尝试）；**可自救**：遇袭时自动抵消，等同「急救箱」。杀与救共用这一次次数。

**化学家**
- 通用【现场调查】×2：见 §3.1 词条。
- 反派【缓释毒剂】×1：谋杀窗口对同房一名非反派下毒（占用本窗口尝试）。**走空手谋杀判定**（不算凶器）：人数限制（亮房非反派 ≤1 / 黑暗不限）与空手附加条件（另一名杀手在场/体格 ≥/男对女，黑暗豁免）均适用；**不可被任何手段防御**。目标不知情、照常行动，**当天晚上睡梦中死亡**（案发房间 = 死者卧室，时段 = 晚间休息，伤痕 = 毒或药物），次日清晨公告。已中毒的目标不可再成为任何谋杀/技能杀的对象（谋杀菜单中直接排除）。下毒那一刻即计入谋杀行为（重置无杀倒计时，见 §8），并视为当天那起成功谋杀——当天剩余窗口不再开放谋杀（毁证窗口照常）。

**运动员**
- 通用【敏捷闪避】×1（被动）：你成为谋杀目标时自动触发，本次谋杀失败。效果等同「急救箱」（可以防御不明药剂与舞台魔术）。
- 反派【强袭】×1：谋杀窗口空手强杀一名目标（占用本窗口尝试）。**无任何附加条件**（体格/性别/同伙在场均豁免）、**不可被任何手段防御**；但仍受正常谋杀的人数限制（亮房非反派 ≤1 / 黑暗不限）。武器伤痕为"空手"。

**黑客**
- 通用【远程入侵】×1：见 §3.1 词条。
- 反派【篡改投票】×1：投票阶段，修改投票数据强迫一名玩家投给你指定的人。结果公布时，所有人只会得知"票数被更改过"，不知道细节。（心理医生的同名技能是心理暗示，效果相同。）

**心理医生**
- 通用【看破伪装】×2：见 §3.1 词条。
- 反派【篡改投票】×1：投票阶段，以心理暗示强迫一名玩家投给你指定的人。结果公布时，所有人只会得知"票数被更改过"，不知道细节。（黑客的同名技能是修改投票数据，效果相同。）

**建筑师**
- 通用【封闭空间】×1：公共发言阶段可声明邀请某些人（也可不邀请）随你进入某房间；自由活动时间你进入目标房间后可立即发动，将该房间大门临时锁死至下一个自由活动时间，除你与你许可的人外任何人无法进出（【暴力破解】与停电均无效；不能对会客室使用——开放大厅没有可锁的大门）。
- 反派【密道谋杀】×1：古堡中存在一条密道网。任意行动阶段（自由活动/晚间休息）的谋杀窗口，你可以选择经密道现身**会客室/书房/监控室/地下室**之一（不能通往卧室）并对该房间的目标动手——菜单会实时列出各出口当前状态（明/暗、在场非反派数、是否满足谋杀条件）。这走**正常谋杀判定**：人数限制、凶器/空手及附加条件、自卫矩阵全部适用（黑暗房豁免附加条件）；占用本窗口尝试。监控与众人眼中你当阶段一直在自己卧室（不留进入记录、不上夜宿名单）。杀后你人在现场：可缴获道具、可在毁证窗口篡改案件（与正常谋杀同口径）。整局限成功一次；成功使用一次后密道损毁。

**机械师**
- 通用【暴力破解】×2：见 §3.1 词条。
- 反派【延时装置】×1：自由活动或晚间休息的房间行动阶段，在你所在的非卧室房间（会客室/书房/监控室/地下室）秘密设置装置。设置当阶段不会触发；从下一阶段起，每个**谋杀窗口**内若装置所在房间恰好只有一名非反派独处，主神会私密推送"机关感应到猎物，是否启动"，由你远程决定（占用本窗口尝试；仅当天尚未成功击杀时会收到推送；你已死亡则装置失效）。无法被【敏捷闪避】/「急救箱」防御。该案件的武器伤痕结论为"机关"。装置未启动前一直有效，触发或被拆除前你不得再次设置。整局限设置一次。

**魔术师**
- 通用【看破伪装】×2：见 §3.1 词条。
- 反派【舞台魔术】×1：在任意人数的非反派角色在场时，可空手完成谋杀；可被「急救箱」/【敏捷闪避】/【药理学】/药用的「不明药剂」抵消（抵消则谋杀失败、消耗本窗口尝试、计入未遂；武器不能防御空手）。在场者当场只会察觉些许奇怪的动静，不知道发生了什么、也不知道是谁造成的——**不会意识到发生了谋杀**；死讯在尸体被后来进入现场的人发现、或次日清晨公告时才公开。该案件的武器伤痕结论为"空手"，杀手线索正常指向你本人。

## 3.1 技能词条

- 【看破伪装】：公共发言阶段、自己发言之前使用，获知指定一名玩家**此前发言中关于"职业、道具、技能、行踪"的声明**是否含有谎言（行踪 = 声称去过的房间与做过的房间行为）。无法验证"我是不是凶手/反派"之类的声明。**这是对声明真伪的直接判定：职业/技能看是否真正拥有（用掉的技能仍是拥有），道具看是否曾经持有（开局分配或后来获得过——用掉、送出、被缴获的都算曾经持有），行踪看是否真正进入过——与监控是否有记录无关，停电、监控抹除、任何隐匿手段都不影响判定。**
- 【现场调查】：清晨案件调查阶段对某起案件使用，**一次获知全部四项真实结论**：① 死亡时间（哪个时间阶段）；② 尸体是否被移动过；③ 武器伤痕（利器 / 钝器 / 枪 / 毒或药物 / 空手 / 机关 / 雕像 / 电线）；④ **杀手线索**——凶手本人的一项特征：性别 / 国籍 / 体格（按角色表文字口径报「健壮或魁梧」/「普通或瘦弱」，由主神按体格数值判定）。同一起案件所有人查到的都是同一项特征（理解为现场留下的线索）；对延时装置/舞台魔术/密道谋杀/药理学/缓释毒剂/强袭造成的案件，线索指向发动者本人。**调查结论由调查者本人当众宣读（含调查者姓名与实际消耗的调查手段），不再私下告知。每起案件由首个实际调查者定型**，之后其他人无需也不能重复调查。反派持调查能力时在清晨调查队列中可改为**篡改并宣读**：只消耗一次调查次数，随机篡改四项中的两项（私下告知改了哪两项、改成什么），随后由本人按正常调查的同口径当众宣读被污染的结论，案件立即定型；篡改行为本身不会被任何人发现（详见 §7.1）。
- 【暴力破解】：打开一扇上锁的房门或保险箱。来源有三种：机械师的职业技能【暴力破解】（×2）、道具「万能钥匙」（×2）、道具「螺丝起子」（×1）。打开后：书房/监控室/地下室的门与保险箱**永久保持开启**；**会客室与卧室每天夜间重新落锁**（卧室被他人开锁进入后，下一个时间阶段即恢复上锁）。**反派**持有任一来源时，可在自由活动开始前消耗一次【暴力破解】拉电闸停电（见 §7.5）——平民的【暴力破解】不能用于停电。
- 【远程入侵】：任意行动阶段（自由活动/晚间休息）远程**查看**当前监控记录（等同进监控室查看，无需到场）。**反派**额外可远程**抹除**某天某时段（白天 = 自由活动 / 晚上 = 晚间休息）的全部监控记录——抹除永不恢复，宣读时注明缺失，等同停电空白。查看或抹除任选其一。
- 【篡改投票】：投票阶段强迫一名玩家投给你指定的人；结果公布时所有人只会得知"票数被更改过"（黑客/心理医生的反派技能，见 §3）。

## 4. 道具一览（12 种）

除标注外，每个道具限用 1 次，用后销毁。道具可在**每天聚会结束后**（自由活动/晚间休息）向同房者**当面赠送**（对方可拒绝；明亮房间同房者看得见、黑暗房间无人知晓——见 §7.5/§7.7 与 §9.6）。

### 凶器（4 种）

仅杀手可用以杀人（§7.6）。平民持有凶器仅可用于自卫——自卫克制：枪防刀与棍、刀防棍、棍防刀、枪无法被武器自卫；自卫不消耗凶器（含环境凶器在内的完整攻防对照见 §7.6 表）。

| 凶器 | 次数 | 效果 |
| ---- | ---- | ---- |
| 左轮手枪 | 1 | 持枪者面对刀/棒球棍的袭击时可自卫 |
| 刀 | 1 | 持刀者面对棒球棍的袭击时可自卫 |
| 棒球棍 | 1 | 持棍者面对刀的袭击时可自卫 |
| 不明药剂 | 1 | 药毒两用：作为凶器仅杀手可用以杀人（可被「急救箱」/【敏捷闪避】/【药理学】/药用的不明药剂防御，武器无法自卫）；任何持有者遇袭时可将其当作药使用，效果等同「急救箱」（防御一切袭击，含不明药剂本身与舞台魔术），用后消耗 |

### 通用道具（5 种）

平民通用道具池的主体（§2 道具池）。

| 道具 | 次数 | 效果 |
| ---- | ---- | ---- |
| 急救箱 | 1 | 面对任何凶器（含不明药剂、环境凶器）与舞台魔术可自卫 |
| 手电筒 | 2 | 身处黑暗房间（地下室/停电房间/夜间卧室）时可选择使用：本阶段该房间不视为黑暗——房间内所有人互相可见、可正常交谈、谋杀按亮房条件判定（使用时机：进入结算后的手电筒判定，见 §7.5/§7.7） |
| 测谎仪 | 1 | 等同【看破伪装】 |
| 鲁米诺试剂 | 1 | 等同【现场调查】（结果公开，见 §3.1 词条与 §7.1） |
| 窃听器 | 2（收听） | 自由活动或晚间休息，在你所在的非卧室房间作为房间行动秘密放置（含会客室——它是唯一能**听到会客室交谈**的手段；监控只记录谁进入，听不到谈话）；只记录放置后发生的交谈。之后任意一天**晚间休息**，你身处自己卧室时可收听一次：获得当天自由活动时段该房间内、放置后发生的全部交谈记录 |

### 反派道具（2 种）

由一名杀手开局持有其一（§2），或经保险箱开出、或以"未分出的那件"进入平民道具池。

| 道具 | 次数 | 效果 |
| ---- | ---- | ---- |
| 可疑的粉末 | 1 | 等同【现场调查】（与鲁米诺试剂同效：四项结论一次获知、结果公开）。**反派持之**还可在清晨调查队列中选择篡改并宣读（随机篡改两项，随后由你按正常调查的同口径当众宣读假结论，本案立即定型——见 §7.1）；平民持有只能正常调查 |
| 木马程序U盘 | 1 | 等同【远程入侵】：远程查看当前监控记录；**反派持有**额外可远程抹除某天某时段的全部监控记录（抹除永不恢复）。查看或抹除任选其一，用掉即销毁 |

## 5. 房间

| 房间 | 锁 | 人数上限 | 环境凶器 |
| ---- | ---- | ---- | ---- |
| 会客室 | 白天无锁；入夜自动落锁（停电时失效，第 4 天起不再上锁） | 不限 | 无 |
| 书房 | 无锁；保险箱上锁 | 3 | 雕像 |
| 监控室 | 上锁 | 2 | 无 |
| 地下室 | 无锁；永久黑暗 | 3 | 电线 |
| 卧室（每人一间） | 白天不开放；夜间本人自由进入，非本人需开锁或被邀请 | 2 | 无（但夜间黑暗，见下） |

- 开锁手段统称【暴力破解】（机械师的职业技能或道具「万能钥匙」/「螺丝起子」，见 §3.1 词条）。书房/监控室/地下室的门与保险箱被打开后**永久保持开启**；**会客室与卧室每天夜间重新落锁**（卧室被他人开锁进入后，下一个时间阶段即恢复上锁）。**停电期间所有门锁失效（保险箱除外）；供电恢复后，卧室重新上锁。**
- 第 4 天起，除卧室外所有门锁自动打开。但封闭空间技能仍可使用。
- **会客室**：白天会议场所，自由活动时间同样开放。壁炉长明——**永不黑暗**（停电也不受影响）。监控覆盖其门口（§9.1）。**桌上物品**：开局时桌上放有「左轮手枪」（§2）；遗嘱中未指定归属或被拒收的道具也会放回桌上（§7.3）。白天任何人不能拿取桌上物品（开放大厅、众目睽睽）；夜间身处会客室且室内只有你自己时，可取走一件（取用行为无人看见，但桌上物品的变动次日清晨公告）。**反派谋杀临时取用**：反派在会客室发动谋杀时，可将桌上凶器视同环境凶器临时取用——无需事先持有、无需动作，用后消耗（消耗记入次日清晨的桌上物品变动公告）。**夜间归宿可选会客室**：入夜大门自动落锁——【暴力破解】可开锁进入（开锁后当夜他人可随入；夜锁每天重新落下）；停电期间门锁失效，任何人可直接进入。夜宿人数不限；大厅明亮，谋杀按亮房条件判定（§7.6）；夜宿者 ≥2 人时睡前可围炉夜谈（即亮房正常交谈，§7.7）；**夜宿者名单次日清晨公开**。【封闭空间】不能对会客室使用。
- **卧室白天清场**：白天会议结束（进入自由活动）后，卧室一律上锁，任何人（含本人）不得进入或逗留，直至晚间休息。
- **卧室夜间黑暗**：晚间休息时卧室没有照明，一律视为黑暗房间（谋杀条件放宽至非反派 ≤2、空手谋杀豁免附加条件、房内行为不可见、受邀组合可摸黑低语——见 §7.6/§7.7）。黑暗中非反派不知道房内有谁；反派仍能知道在场者的具体身份，但也仅限于知道人员，其他黑暗效果不变（见 §9.5）。
- **地下室**：永久黑暗。黑暗房间内无法进行交谈；其中的谋杀不设非反派人数限制（房间容量仍是硬约束，见 §7.6）。停电后，任何人可前往地下室修复发电机，成功则供电恢复（停电结束）；**无人修复则停电一直持续（跨日延续），不会自动恢复**。
- **监控室**：进入可查看监控记录（见 §7.2 与 §9）。
- **书房保险箱**：打开者获得其中道具（内容开局已全员公告，见 §2；非黑暗时同房者看得见开箱行为与取走的道具，黑暗中无人知晓）。
- **环境凶器**：书房雕像 / 地下室电线。**只能用于攻击，不能用于防御**；杀手在场满足谋杀条件时可使用，不限次数。**雕像**视同刀/棍类攻击——可被「刀」/「棒球棍」/「左轮手枪」武器自卫（急救箱/敏捷闪避等救援系手段同样有效）；**电线**不可被任何手段防御（武器与救援系均无效）。武器伤痕结论为"雕像"/"电线"——会直接暴露案发房间。

## 6. 时间轴与行动顺序

一天 = 三个时间阶段：

| 阶段 | 位置 | 可否行凶 |
| ---- | ---- | ---- |
| 案件调查 + 公共发言 + 投票（合称"白天会议"） | 会客室（全员） | 不可 |
| 自由活动 | 会客室 / 书房 / 监控室 / 地下室（白天卧室清场） | 可 |
| 晚间休息 | 自己卧室 / 他人卧室 / 会客室 / 书房 / 监控室 / 地下室（与自由活动同构，§7.7） | 可 |

- **谋杀从第 1 天自由活动起开放**，普通谋杀与反派职业技能杀均按各自条件执行；第 1 天没有投票，"公共发言"时段改为**侦探竞选**（见 §7.4）。
- **反派密谋频道**：每天两次固定（均含第 1 天）——① 公共发言/投票结束后、自由活动开始前（先于停电声明轮）；② 晚间休息选房前。每次两名杀手按行动顺序各发一段密谋发言（纯文本、不含动作、互相可见、对其他人完全不可见；每人只发一段，不多轮）。两次密谋无条件进行，不随当天谋杀是否已发生而取消；一名杀手出局后频道自然消失。
- **第 6 天是终审日**：只进行白天会议（案件调查/公共发言/交换/投票），没有自由活动与晚间休息；终审投票结束后仍无阵营获胜，主神降临（见 §8）。
- 行动顺序：第 1 天完全随机；之后每天开始时，将顺序首位移到最后。
- 顺序靠后者在行动前可以看到顺序靠前者的公开声明（如白天房间去向声明、发言内容）；房间的开锁与进入结果在去向声明收齐后统一结算（§7.5）。

## 7 阶段细则

### 7.1 清晨与案件调查

- 每天清晨，主神公告：上一日（自由活动与晚间）发生的全部**死亡**及案发房间——有报案人时一并刊出（报案人 = 此前进入现场发现尸体并选择报案的人；无人报案则不刊出）。谋杀未遂也会公告（"某人遇袭但幸存"，不公布袭击者与方式）。**死亡与未遂在发生时不即时公告——没人知道白天或夜里是否出过事，直到次日清晨**（进入现场者可提前私下发现，见 §7.6"发现与报案"；遇袭的目标仍会当场私下得知）。**公告不含事发时段，时段只能由调查获知**。
- 若案发房间当时上锁，强制打开并公告此事实。
- 死者的职业若从未公开过，此时公开（身份不公开——只有投票出局才揭示身份）。
- 夜宿会客室者名单此时公开（见 §5）。
- 会客室桌上物品的变动（夜间被取走 / 遗嘱放回）此时一并公告。
- **已永久开启的门与保险箱清单**此时一并公告（谁都可以走近看出门没锁——这只是台账追认）。
- **监控公开**：主神公开宣读原始监控记录：**案发当日全天（自由活动 + 晚间休息两个时段）**× 两个场所（案发房间 + 死者卧室）的进入者名单。监控只记录"进入"，不记录房间内的行动和对话。被【远程入侵】/「木马程序U盘」抹除的时段注明缺失（等同停电空白）。
- **清晨调查队列**：公告案件后，持有调查能力（【现场调查】/「鲁米诺试剂」/「可疑的粉末」，含反派）的角色按行动顺序逐一处理每起尚未定型的案件。每次宣读都会同时公开调查者与实际消耗的调查手段：
  - **平民：自动调查**——无需声明，结论由本人当众宣读（向全员公开四项真实结论）；每个未查案件消耗一次次数；多起案件并存时按案发先后分配，持有者与次数用尽即止。
  - **反派：私密菜单三选一**——① **篡改并宣读**（限本案此前未被篡改且尚未被任何人调查；只消耗一次调查次数，随机篡改四项中的两项并私下告知明细，随后由你按正常调查的同口径当众宣读假结论，案件立即定型）；② **正常调查**（你当众宣读真实结论——第一个公开调查的人能攒清白度，案件立即定型）；③ **跳过**（不消耗次数，顺延给下一位持有者）。
  - **每起案件由首个实际调查者定型**：正常调查或篡改并宣读都会立即定型，之后其他人无需也不能再处理本案；若无人持有调查手段或所有持有者都跳过，本案永不调查。同一案件只能篡改一次。
- **篡改的另一处窗口（毁证窗口）**：案发当天，身处案发现场的反派可在阶段末篡改（亮房中此行为会被同房者看见——与毁证可见性同口径；见 §7.6"成功后果"）。毁证只污染案件，不直接公开也不封闭调查。次日清晨不再给反派三选一，而由行动顺序中首位仍持有调查手段者（无论平民或反派）自动消耗一次并宣读被污染的结论；提前篡改者若排在首位且有剩余次数，也同样消耗。若已无人持有调查手段，本案不再公告调查结果。清晨的篡改并宣读只能用于此前未篡改且未被调查的案件。
- 尸体上未被拿走的未使用道具此时被收走封存，随后由死者的遗嘱（"死者留下的字条"）指定归属（见 §7.3）。

### 7.2 公共发言

- 第 2 天起，每天按行动顺序每人发言一次（**侦探末置发言**；第 1 天该时段为侦探竞选，见 §7.4）。
- 发言内容不限：分析、指控、质疑、声明、辩护均可；可向顺序靠后者提问。
- 发言结束后（第 2 天起）进入投票（§7.3）。道具赠送不在会议中进行——每天聚会结束后（自由活动/晚间休息）向同房者当面赠送，见 §7.5/§7.7 与 §9.6。

### 7.3 投票与出局

- 第 2 天起，每天公共发言后投票。可弃权。**侦探的一票计 1.5 票**，其余人各计 1 票。得票**超过**当前存活人数一半者出局（平票、未过半则本次无人出局）。
- 出局者先发表**遗言**（可以撒谎；若有未使用的遗留道具，在遗言中一并立**遗嘱**：逐件指定归属，接收人须为存活玩家），随后主神公布其**身份（平民/杀手）与职业**。
- **遗嘱**：出局者与当天尸体上封存的未使用道具，由本人逐件指定归属——被谋杀者以"死者留下的字条"形式于次日清晨指定。每件道具的接收人可当场**拒收**；接受的道具**当天即可用**。遗嘱的道具名、来源与去向全部公开。**立遗嘱时可附言——遗言与死者字条的内容同样公开**。**道具不会被丢弃**：未指定归属或被拒收的道具不销毁，一律放回会客室桌上（§5 桌上物品）。侦探出局时，侦探徽章也随遗嘱指定归属（见 §7.4）。
- **武装指认**（第 2 天起，即首次投票起）：平民指认某人为杀手——**两名杀手都是正确目标**：**指认正确 → 被指认的杀手出局**（遗言→身份公布→遗嘱，流程同投票出局；若两名杀手已全部出局，平民获胜，否则游戏继续）；**指认错误**（所指为平民）→ **指认者出局**（公众由此可知被指认者不是杀手）。**发动时机**（均在投票结算后、出局执行前）：① 一次投票未产生出局者时；② 投票将导致**最后一名平民**出局时——该平民在出局执行前仍可发动（背水一战）。每次投票至多接受一次指认（按行动顺序，先声明者优先）；**指认消耗武器（等同攻击）**——自己的武器扣一次次数（用掉即销毁）；临时取用的桌上凶器用掉即消耗、不再放回桌上（无论对错）。**指认者公开发表一句指认宣言。**资格细则：**武装指认仅限平民**；**有侦探时仅侦探本人可行使**（侦探须持有武器——左轮手枪/刀/棒球棍；侦探若为反派则本局无人可指认，反派自己心里清楚）；**没有侦探时**，持有武器的平民可指认，桌上凶器仍在会客室桌上时任何平民也可**临时取用**桌上凶器进行指认。

### 7.4 侦探（第 1 天竞选产生）

- **竞选流程**（第 1 天"公共发言"时段）：
  1. **声明轮**：按行动顺序，每人作一段简短发言并宣告参选或不参选（可顺带宣告自己的职业与道具——可以撒谎，但谎言会留档）。
  2. **密封退选**：若参选者 ≥2 人，参选者各自私下决定继续参选或退选（互不可见，结果一齐公布）；退选者同样没有投票权。各人可附一句理由，随结果一齐公布。
  3. **投票**：留任候选人只剩 1 人则直接当选；超过 1 人时由**自始未参选者**（不含退选者）投票，每人 1 票，得票最多者当选。票型不公开，但投票人可附一句理由，开票后公布。
  4. 无人报名、候选人全部退选、全员参选（无人持有投票权）或投票平票 → **本局不设侦探，不再补选**。
- **职权**：① 当选时获得桌上凶器「左轮手枪」（**侦探佩枪**，公开公告）；② 公共发言末置发言（第 2 天起）；③ 投票时一票计 1.5 票（第 2 天起）；④ **武装指认垄断**：有侦探时仅侦探可进行武装指认（§7.3）。佩枪本身是普通道具：可赠送他人、被谋杀时可被杀手缴获（§7.6）、被票出时随遗嘱分配、用于武装指认时同样消耗（§7.3）。
- **警徽传承**：侦探出局（被谋杀 / 投票出局 / 武装指认失败）时，侦探徽章随遗嘱一并处理——由本人指定一名存活玩家继任（接收人可拒收）；未指定或被拒收则销毁，本局不再设侦探。
- 侦探不是调查垄断者：任何有调查能力的人都能参与清晨调查队列（见 7.1）。

### 7.5 自由活动

1. **停电声明（拉电闸）**：反派可在本阶段开始前秘密声明停电——消耗一次【暴力破解】（职业技能/「万能钥匙」/「螺丝起子」任一）拉开电闸制造过载（电闸不在地下室，无需前往）。平民的【暴力破解】不能用于停电。**停电的发现**：停电后每位玩家在抵达自己所选房间的那一刻才各自发现（灯骤然熄灭、四周一片漆黑、门锁全部失效——留在会客室者则看到走廊灯火尽灭）——在此之前，他人的进入结果不会向你暴露停电；全员进入房间后主神才向众人正式公布。
2. **去向声明**：所有人按行动顺序依次声明去向：**会客室 / 书房 / 监控室 / 地下室**（白天卧室一律清场，不可选择）。此轮只确定意向，不移动任何人。**顺序靠后者在声明前可见顺序靠前者的去向声明与邀请**。可同时向顺序靠后者发出同入邀请（对方可选择更改自己的目的地）；**同入邀请成立时，邀请者会知道对方已到来**（即使在黑暗房间，你也听得见应邀者进来），邀请未成立则不会有任何通知。
3. **开锁行动轮**：去向收齐后，对每一间有玩家准备进入的上锁房间，主神按行动顺序逐一**私密询问**拟进入者中持有【暴力破解】手段的人是否愿意使用；首位愿意者消耗一次手段并开门，成为该房间的开锁者。此轮只处理门锁与剩余次数，不处理位置、容量或邀请；不愿使用者不消耗次数。若无人愿意开门，门保持上锁。
4. **进入与停电结算**：每个房间由开锁者优先进入，其余人仍按行动顺序；随后正常判定人数上限、邀请、【封闭空间】等进入条件。门已在开锁轮打开时，顺序靠前但自己无开锁手段的人也能进入；房间上锁而本轮无人开门、满员、被【封闭空间】挡住或选择无效者无法进入，默认滞留会客室。停电生效时，除会客室外所有房间视为黑暗（地下室恒为黑暗）；**所有门锁失效**（保险箱除外）；**监控停止记录**（空白期，不回溯、供电恢复后恢复记录）。**停电不会自动结束**：一直持续到有人在地下室修复发电机为止——无人修复则跨日延续（次日及之后依然停电）。
5. **手电筒判定**：进入结算后（停电公告之后），身处黑暗房间且持有「手电筒」的玩家按行动顺序逐一决定是否使用——点亮的房间本阶段视为明亮：所有人互相可见、可正常交谈、谋杀按亮房条件判定；已被点亮的房间不再重复询问。
6. **房间交谈**：同房者可自由交谈，每人按行动顺序发言一次，后发言者能看到本房间先发言者的发言（含会客室）。**黑暗房间内无法交谈——例外：同入邀请成立的组合互知在场，可摸黑低声交谈；此时房间内所有在场者（含他们不知道的潜伏者）都能听到内容，交谈者不会知道是否被旁听**（与 §7.7 夜间密谈同口径）。
7. **房间行动**：使用房间设施（查监控 / 修发电机 / 开保险箱等）、**当面赠送道具**（§9.6：限同房者，对方单独回应接受/拒绝）与**报案**（身处有未公告尸体的房间时可用，见 §7.6「发现与报案」）。每人每轮房间行动只能选择一个动作，多报会整批驳回。非黑暗时，这些行为会被同房者看见；黑暗中则无人知道是谁做的。
8. **谋杀窗口**：房间行动结束后的独立环节（§7.6）。**每个谋杀窗口全队至多发动一次尝试**：按行动顺序，第一位有合法手段的杀手先被私密询问；仅"放弃/无合法目标"才顺延给另一位杀手；一旦有人发动（无论成败）本窗口结束。窗口全私密——后收到菜单的杀手可知"本窗口你的同伙尚未动手"（简报会写明）。**成功击杀每天全队至多一起**：白天窗口已有人成功，晚间窗口不再有谋杀（毁证窗口照常）；白天未遂或未发动，晚间窗口正常可用。普通谋杀与反派职业技能杀（药理学/缓释毒剂/强袭/舞台魔术/密道谋杀/延时装置启动）都占用本窗口尝试。与房间行动相互独立：谋杀不消耗房间行动次数，房间设施也不消耗谋杀尝试。

### 7.6 谋杀判定

**发动条件**（杀手在**谋杀窗口**声明发动——房间行动结束后的独立环节；自由活动与晚间休息各一个窗口，每窗口全队至多一次尝试，仅放弃/无合法目标顺延给同伙）：

- 在场非反派角色数：正常 ≤1；黑暗房间不设人数限制（房间容量仍是硬约束）。
- **空手谋杀**还须满足以下**之一**：① 另一名杀手在场；② 本人体格 ≥ 目标体格；③ 本人男、目标女。黑暗房间中（含夜间卧室，见 §5）空手谋杀无任何附加条件。
- **凶器谋杀**：无条件。会客室桌上的凶器可被反派临时取用（见 §5 桌上物品）。
- **环境谋杀**（雕像/电线）：无条件。

**自卫判定**：目标持有能克制该攻击的武器、或持有救援系手段时，谋杀自动失败（全部自动触发，无需目标声明）。救援系 = 「急救箱」/【敏捷闪避】/【药理学】/药用的「不明药剂」，四者等效。攻防对照如下（黑暗房间不设人数限制、空手与缓释毒剂在黑暗中豁免附加条件；密道谋杀按实际所用手段适用对应行）：

| 攻击手段 | 亮房人数限制 | 附加条件 | 武器自卫 | 救援系 |
| ---- | ---- | ---- | ---- | ---- |
| 左轮手枪 | 非反派 ≤1 | 无 | — | ✓ |
| 刀 | 非反派 ≤1 | 无 | 棒球棍、左轮手枪 | ✓ |
| 棒球棍 | 非反派 ≤1 | 无 | 刀、左轮手枪 | ✓ |
| 不明药剂 /【药理学】毒杀 | 非反派 ≤1 | 无 | — | ✓ |
| 空手 | 非反派 ≤1 | 同伙在场 / 体格≥目标 / 男对女 | — | ✓ |
| 雕像（书房环境凶器） | 非反派 ≤1 | 无 | 刀、棒球棍、左轮手枪 | ✓ |
| 电线（地下室环境凶器） | 非反派 ≤1 | 无 | — | — |
| 【舞台魔术】 | **无限制**（唯一无亮房人数限制的手段） | 无 | — | ✓ |
| 【强袭】 | 非反派 ≤1 | 无 | — | — |
| 【缓释毒剂】 | 非反派 ≤1 | 同空手 | — | — |
| 【延时装置】 | 目标独处才触发 | 需预设 | — | — |

多种防御同时可用时，按**武器自卫 → 急救箱 → 药用的不明药剂 → 敏捷闪避 → 药理学**的顺序自动触发；武器自卫不消耗武器，其余防御按实际触发消耗。

**失败后果**：目标得知"有人遇袭"（自己幸存，必然知情），并会私下得知实际触发的防御来源，但不知道袭击者是谁；在场的其他人只听到些许奇怪的动静，不知道发生了什么、是谁造成的。杀手也无法分辨失败原因（是武器、急救箱还是技能）。未遂只消耗本窗口尝试、**不封顶当天**（晚间窗口仍可再试）；未遂计入"无杀倒计时"（见 §8）。

**成功后果**：

- **每天全队至多一起成功谋杀**：本日已有人成功击杀后，当天剩余窗口不再开放谋杀（毁证窗口照常）。
- 若现场没有其他非反派角色：杀手获得尸体上全部未使用道具；**身处案发现场的**杀手可在阶段末的**毁证窗口**篡改本案调查（随机篡改两项结论，见 §7.1）——篡改必须亲自动手，场外反派不会收到通知；亮房中此行为会被同房者看见；**仅限案发当天**：白天的案件当晚仍可前往现场处理，次日清晨案件定型后现场即无法改动。
- 若现场有其他非反派角色：不能拿道具、不能篡改。
- 死亡公告统一在次日清晨发出（见 §7.1；公告不含死亡时段）。
- **发现与报案**：死亡发生时不即时公开。之后第一个进入案发房间的人会当场私下发现尸体（黑暗房间同样触发）——只告知发现者本人；同房的人各自独立决定是否**报案**（房间行动中的独立可选动作，消耗当阶段房间行动名额）：报案者被记录为**报案人**，随次日清晨公告一并公开；不报案则无人知道你知情（你可以照常交谈、守口如瓶，或当场把事情说出去）。两名杀手同样可以回到现场发现尸体并报案。同一房间多人发现可多人并列报案。

### 7.7 晚间休息

晚间休息与自由活动**结构相同**：**去向声明 → 开锁行动轮 → 进入结算 → 手电筒判定 → 房间交谈 → 房间行动**——只是合法去向、锁与明暗不同。所有人的选择**互相不可见**（你看不到别人去了哪里）。晚间休息是发现白天凶案的唯一窗口：若所选房间有尚未公告的尸体，进入者当场私下发现（见 §7.6「发现与报案」）。

1. **选择去向**：按行动顺序依次秘密声明，收齐后先进行开锁行动轮，再统一结算进入：
   - **回自己卧室**（默认）：夜间开放，免费进入。
   - **前往其他房间**：会客室 / 书房 / 监控室 / 地下室 / 他人的卧室。
   - **同入邀请**：可邀请一名顺序在自己之后的玩家同去你的目的地（对方可改选）。邀请成立则互知在场（黑暗中也知道）；对方没来则不会有任何通知。
2. **锁与开锁轮**：开锁轮与白天相同——按行动顺序私密询问拟进入者，首位愿意消耗【暴力破解】手段者开门并在进入轮优先，其余人按原顺序；自己无手段但顺序靠前的人不会被提前劝退。他人卧室上锁——对所有人一视同仁（含反派）：需【暴力破解】手段或受邀才能进入（被他人开锁后，下一个时间阶段恢复上锁）；会客室入夜自动落锁（手段或停电/第 4 天起免费进入，开锁后当夜他人可随入，夜锁每天重新落下）；监控室上锁（首开需手段，开后永久开启）；书房/地下室无锁。**停电期间所有门锁失效（保险箱除外）。**
3. **明暗**：**卧室夜间黑暗**（§5）；地下室永久黑暗；会客室永不黑暗；书房/监控室夜间明亮（停电时黑暗）。
4. **人数上限**：书房 3 / 监控室 2 / 地下室 3 / 卧室 2 / 会客室不限（与白天一致）。满员后他人无法进入——卧室住满 2 人天然挡住后来者（含杀手）。
5. **平民慎入**：平民不敢**非受邀**进入**已有他人**的书房/监控室/地下室——进入失败并私下得知"已经有人了，出于安全考虑，你没有进入"。被邀请者与反派不受此限（反派进入他人卧室仍须开锁或受邀）。
6. **进入失败**：功能房/会客室失败会私下告知简要原因（上锁/已满员/已有他人）；进入他人卧室失败仅告知"无法进入"。无法进入者默认回自己卧室。
7. **手电筒判定**：进入结算后，身处黑暗房间（夜间卧室/地下室/停电房间）且持有「手电筒」的玩家按行动顺序逐一决定是否使用——点亮的房间本阶段视为明亮：所有人互相可见、可正常交谈、谋杀按亮房条件判定。在自己卧室也可以使用——能照出偷偷摸进来的人，对方若试图空手谋杀也无法绕过附加条件。
8. **房间交谈**：亮房正常交谈；黑暗房间无法交谈——例外：同入邀请成立的组合可摸黑低语，此时房间内所有在场者（含他们不知道的潜伏者）都能听到内容，交谈者不会知道是否被旁听（与 §7.5.6 同口径）。卧室两人密谈、会客室围炉夜谈均按此口径。
9. **房间行动**：查监控（监控室）/ 修发电机（地下室）/ 开保险箱（书房）/ 收听窃听器（自己卧室，见 §3.1）/ 取桌上物品（会客室独处，见 §5）/ 使用技能与道具 / **当面赠送道具**（§9.6：限同房者，对方可拒绝）/ **报案**（身处有未公告尸体的房间时可用，见 §7.6「发现与报案」）。每人每轮房间行动只能选择一个动作，多报会整批驳回。非黑暗时这些行为会被同房者看见；黑暗中则无人知道是谁做的。
10. **谋杀窗口**：房间行动结束后的独立环节（见 §7.6）——口径与白天相同：每窗口全队至多一次尝试，仅放弃/无合法目标顺延给同伙；若白天窗口已有人成功击杀，本窗口不再开放谋杀。卧室夜间黑暗 → 非反派 ≤2、空手豁免；进入空房间没有目标，不消耗尝试。
11. **夜宿会客室**：夜宿者名单次日清晨公开（大厅无隐私）；桌上物品变动次日清晨公告（§7.1）。

## 8. 胜负条件

- **平民胜利**：两名杀手全部出局（投票或武装指认）；或无杀倒计时完成。
- **无杀倒计时**：**从第 1 天起算**。若连续**两个完整天**（自由活动+晚间休息）没有任何谋杀行为，则下一个清晨平民直接获胜（第 1、2 天均无谋杀行为 → 第 3 天清晨平民获胜）。谋杀行为 = 真正进入攻击判定（击杀成功或被防御的未遂；缓释毒剂以下毒那一刻计入）；未发动（含进入空房间没有目标）不计入。
- **反派胜利**：所有平民死亡或被投票出局。（残局不打折扣：哪怕只剩 1 名平民，也要真正杀光或票光才算赢——决斗与反杀都可能发生。）
- **主神胜利**：第 6 天终审投票结束时仍无阵营获胜（包括从未发生任何谋杀行为的情况），则**全员失败，主神获胜**。

## 9. 关键裁定速查

1. **监控**：只记录"某时间段谁进入了某场所"，不记录房间内行为。监控覆盖所有房间门口（含会客室）；监控室上锁（首开需【暴力破解】手段），人数上限 2。反派可以【远程入侵】/「木马程序U盘」远程抹除某天某时段的全部记录（抹除永不恢复，宣读时注明缺失）。经密道谋杀者的进入不留记录（记录上此人一直在自己卧室）。**停电期间监控缺失（不记录）；清晨宣读时缺失会注明。清晨公开宣读覆盖案发当日全天（自由活动 + 晚间休息两个时段）×（案发房间 + 死者卧室）。**
2. **看破伪装**：只验证"职业、道具、技能、行踪"四类声明是否为谎言。"我是清白的"等声明不在验证范围内。行踪按事实判定（是否真正进入过该房间），与监控记录无关——停电与监控抹除不影响判定。
3. **死亡公告**：谋杀与未遂**不在发生时即时公告**，统一在次日清晨公告"谁死了/谁遇袭 + 案发房间"，有报案人时一并刊出；公告不含事发时段——时段只能由调查获知（篡改因此可能伪造死亡时间）。进入案发房间者会当场私下发现尸体（见 §7.6「发现与报案」）；遇袭的目标仍会当场私下得知。
4. **身份揭示**：只在**出局**时发生（投票出局、武装指认正确处决杀手、武装指认失败——遗言在揭示之前）；身份只有**平民/杀手**两档。死亡不揭示身份，只揭示职业（若此前未公开）——但遗留道具随遗嘱公开（§7.3）。
5. **黑暗**：地下室永久黑暗；会客室永不黑暗；**卧室夜间黑暗**；停电期间除会客室外全部黑暗；**手电筒点亮的房间本阶段不视为黑暗**（进入结算后的手电筒判定，§7.5/§7.7）；黑暗 = 房间交谈无法进行（例外：同入邀请成立的组合可摸黑低语，全体在场者含潜伏者都能听到，§7.5.6/§7.7）+ 谋杀不设非反派人数限制（房间容量仍是硬约束）+ 空手谋杀豁免附加条件 + 房间内行为不可见。**反派在黑暗房间仍能知道在场者的具体身份；这只是人员信息例外，以上交谈、行为不可见与谋杀判定均不因此改变。**
6. **道具**：默认限 1 次（手电筒、万能钥匙、窃听器收听为 2 次）；转手不影响剩余次数；出局者/死者的未使用道具经遗嘱指定归属，接受后**当天即可用**；未指定归属或被拒收的道具不销毁，放回会客室桌上（见 §5 桌上物品）。**当面赠送**：每天聚会结束后（自由活动/晚间休息），可向同房者赠送道具——对方单独回应接受/拒绝；明亮房间同房者看得见交易（道具名不公开），黑暗房间无人知晓。
7. **侦探**：第 1 天竞选产生（声明轮 → 密封退选 → 未参选者投票；平票/无人参选/全员参选则本局无侦探，不补选）；职权=桌上佩枪 + 末置发言 + 1.5 票权 + 武装指认垄断；出局时警徽随遗嘱传承或销毁，佩枪按普通道具处理（可被缴获/赠送/遗嘱分配）。
8. **次数与合法性**：主神掌握全部技能/道具剩余次数；声明使用不存在的手段、次数耗尽的技能或不满足条件的动作，会被直接驳回并私下告知本人（可当场重新声明一次；其他人不会知道）。
9. **桌上物品**：开局时桌上放有「左轮手枪」；遗嘱未指定/被拒收的道具也放回桌上。白天不可拿取；夜间独处会客室者可取走一件；反派谋杀可在会客室临时取用桌上凶器（视同环境凶器，无需持有，用后消耗）；变动次日清晨公告。
10. **昼夜统一进入结构**：自由活动与晚间休息均采用去向声明 → 独立开锁行动轮 → 进入结算（开锁者优先，其余按行动顺序）→ 手电筒判定 → 房间交谈 → 房间行动 → 谋杀窗口（独立环节，不占房间行动）；白天靠后者可见前者的去向声明，晚间的去向互相不可见。他人卧室上锁（对所有人含反派一视同仁，受邀除外）；卧室夜间黑暗；平民非受邀不敢进入已有他人的功能房（被邀请者与反派豁免）；卧室满 2 人天然挡住后来者（含杀手）；谋杀窗口每天两个（自由活动/晚间休息各一），**每个窗口全队至多一次尝试**（仅放弃/无合法目标顺延给另一位杀手），**每天全队至多一起成功谋杀**。
