# 暴风夜 · 6 人局规则书 v3.32

> 你在古堡中醒来，失去了记忆。大厅的桌上放着这本册子。所有人都能看到这本册子的内容。
> 你可以就任何事实撒谎，但你声明的"动作"必须合法——非法动作会被主持人直接驳回（私下告知你，可当场重新声明一次）。
> 每个阶段，主持人都会给你一份"当前合法动作"的菜单；菜单之外的事你做不到。遇到册子上没写的事，主持人会临场解释。
> 你听到的每句话都可能是谎言；主持人发布的每条公告都是真的。

---

## 1. 阵容与身份

本局共 6 名玩家。**角色表（每人的名字 / 性别 / 体格 / 国籍）由主持人在开局时创建，并全员公布**；本规则书不含固定角色表。

身份分配（随机，互不知晓）：**平民 ×4、帮凶 ×1、杀手 ×1**。

- 杀手与帮凶合称"反派"，开局时互相知道对方的身份、职业、道具。
- 杀手是唯一拥有**主动谋杀权**（§7.6）的人；帮凶不能主动谋杀——反派职业技能造成的击杀不受此限（见 §3 说明）。
- 杀手被投票出局时，帮凶立即继任为杀手（仅私下通知本人，不公开公告）。
- 体格数值用于空手谋杀判定（见 §7.6）。

## 2. 开局分配

- 每人随机获得 **1 个职业**（9 选 6，不重复）。本局未出现的职业与道具对所有人保密——任何人都不能确定某个职业或道具是否在本局中（例外：万能钥匙、螺丝起子、桌上凶器与四件凶器的去向结构是公开规则，见下）。
- 道具按车道分配：
  - **杀手**：凶器×1 + 「万能钥匙」（反派开锁手段固定在线）。
  - **帮凶**：凶器×1 + 随机 1 件反派道具（可疑的粉末/裹尸袋/病毒 U 盘 之一）。反派的两件凶器为 刀 / 棒球棍 / 不明药剂 中互不重复的两件（「左轮手枪」不进反派车道，见下）。
  - **平民（4 人）**：其中随机 1 人固定获得「螺丝起子」；其余 3 人从通用道具池（急救箱/手电筒/测谎仪/鲁米诺试剂/窃听器，5 选 3）各随机抽 1 件。平民拿到武器仅可用于自卫；拿到不明药剂则可当救命药（见 §3.1）。
- **桌上凶器**：会客室桌上固定放有一把「左轮手枪」（主人的收藏，开局全员公告）。白天任何人不能拿取（开放大厅、众目睽睽）；第 1 天侦探竞选产生侦探后归侦探持有（§7.4）；若无人持有，夜间独处会客室者可取走（§5、§7.7）。**四凶器仍然全部入场**：反派 2 件 + 桌上 1 件 + 保险箱或平民 1 件。
- 书房保险箱内放置 1 件道具：从**未被分配的剩余凶器 + 剩余反派道具**中随机（即可能是凶器也可能是反派道具；若抽中反派道具，剩余的那件凶器改由随机一名平民获得）。**开局时主持人全员公告保险箱的具体内容（主人留下的字条）。**
- 开局准备阶段：反派互认；反派建筑师获知密道网的存在（见 §3【建造密道】，无需选定出口）。窃听器不在此阶段放置，须由持有者后续进入目标房间后设置（见 §4）。

## 3. 职业一览（9 种）

技能分"通用"（任何人都可用）与"反派"（仅杀手/帮凶可用）。次数均为整局限定。**反派技能不受 §1"帮凶不能杀人"的限制**：帮凶也可正常发动【延时装置】【舞台魔术】等反派技能、并可经【建造密道】当场动手谋杀，由此造成的击杀归属于发动者本人（犯罪侧写结论同样指向发动者，见犯罪侧写师条目）。

**医师**
- 通用【现场调查】×2：见 §3.1 词条。
- 反派【伪造痕迹】×1：某起谋杀发生后，使该案件所有【现场调查】/「鲁米诺试剂」的结果中，除「武器伤痕」外的选项全部得到错误结果。

**化学家**
- 通用【现场调查】×2：见 §3.1 词条。
- 反派【销毁证物】×1：同上，但仅「死亡时间」保持正确。

**运动员**
- 通用【敏捷闪避】×1（被动）：你成为谋杀目标时自动触发，本次谋杀失败。效果等同「急救箱」（可以防御不明药剂）。
- 反派【转移尸体】×1：某起谋杀成功后，将尸体移动到另一个房间而不被发现。

**黑客**
- 通用【暴力破解】×1：见 §3.1 词条。
- 反派【信号干扰】×1：见 §3.1 词条。

**犯罪侧写师**
- 通用【犯罪侧写】×1：案件调查阶段使用，获知杀手本人的一项特征：性别 / 国籍 / 体格（按角色表文字口径报「健壮或魁梧」/「普通或瘦弱」，由主持人按体格数值判定）。对延时装置与舞台魔术造成的案件，结论指向设置者/表演者本人。
- 反派【伪造证物】×1：某起谋杀发生后，使该案件所有【现场调查】/「鲁米诺试剂」的结果中，除「尸体转移」外的选项全部得到错误结果。

**心理医生**
- 通用【看破伪装】×2：见 §3.1 词条。
- 反派【记忆植入】×1：投票阶段，强迫一名玩家投给你指定的人。结果公布时，所有人只会得知"票数被更改过"，不知道细节。

**建筑师**
- 通用【封闭空间】×1：公共发言阶段可声明邀请某些人（也可不邀请）随你进入某房间；自由活动时间你进入目标房间后可立即发动，将该房间大门临时锁死至下一个自由活动时间，除你与你许可的人外任何人无法进出（【暴力破解】与停电均无效；不能对会客室使用——开放大厅没有可锁的大门）。
- 反派【建造密道】×1：开局前你确认古堡中存在一条密道网（无需指定出口）。任意一天的**晚间休息**，你可以选择经密道前往**会客室/书房/监控室/地下室**之一（不能通往卧室）——这即是你当夜的去向，与其他夜间行动互斥，但不受房间人数上限与"平民慎入"限制。进入条件与谋杀的人数条件相同：出口房间当时在场非反派角色 ≤1（黑暗房间不设人数限制——房间容量仍是硬约束）；不满足则当晚无法使用（密道保留、不暴露）。成功进入时，监控与众人眼中你当晚一直在自己卧室（不留进入记录、不上夜宿名单）；你可以在该房间正常行动（房间设施/技能/道具；若你是反派——杀手或帮凶——可发动谋杀：帮凶借密道动手不受"帮凶不能主动谋杀"限制，击杀归属于发动者本人，消耗当阶段谋杀机会，受 §7.6 全部条件约束）。成功使用一次后密道损毁；整局至多成功一次。停电不影响密道使用；出口房间的谋杀条件按当时明/暗状态判定。

**机械师**
- 通用【暴力破解】×1：见 §3.1 词条。
- 反派【延时装置】×1：自由活动或晚间休息的房间行动阶段，在你所在的非卧室房间（会客室/书房/监控室/地下室）秘密设置装置。设置当阶段不会触发；从下一阶段起，每次进入结算后、手电筒判定前检查：若该房间处于"只有一名非反派角色单独进入"的状态，装置自动触发将其击杀（无需你在场，不占用你当阶段的谋杀机会）。无法被【敏捷闪避】/「急救箱」防御。该案件的武器伤痕结论为"机关"。装置未触发前一直有效，触发或被拆除前你不得再次设置。整局限设置一次。

**魔术师**
- 通用【看破伪装】×2：见 §3.1 词条。
- 反派【舞台魔术】×1：在任意人数的非反派角色在场时，可空手完成谋杀，无法被【敏捷闪避】/「急救箱」防御。在场者当场只会察觉些许奇怪的动静，不知道发生了什么、也不知道是谁造成的——**不会意识到发生了谋杀**；死讯在尸体被后来进入现场的人发现、或次日清晨公告时才公开。该案件的武器伤痕结论为"空手"，犯罪侧写正常指向你本人。

**（说明）**：所有职业的反派当杀手时，空手谋杀均须满足 §7.6 的体格/性别条件——魔术师与机械师不再有额外限制。

## 3.1 技能词条

- 【看破伪装】：公共发言阶段、自己发言之前使用，获知指定一名玩家**此前发言中关于"职业、道具、技能、行踪"的声明**是否含有谎言（行踪 = 声称去过的房间与做过的房间行为）。无法验证"我是不是凶手/反派"之类的声明。**行踪验证以监控记录为准；对局存在停电空白（监控缺失时段）时，"无记录"不构成谎言证据——相关行踪声称判"无法验证"，不计入谎言判定。**
- 【现场调查】：案件调查阶段对某起案件使用，从三项中任选一项获知真实结论：① 武器伤痕（利器 / 钝器 / 枪 / 毒或药物 / 空手 / 机关 / 雕像 / 电线）；② 死亡时间（哪个时间阶段）；③ 尸体转移（是否被移动过）。
- 【暴力破解】：打开一扇上锁的房门或保险箱。来源有三种：黑客/机械师的职业技能【暴力破解】（×1）、道具「万能钥匙」（×2）、道具「螺丝起子」（×1）。打开后：书房/监控室/地下室的门与保险箱**永久保持开启**；**会客室与卧室每天夜间重新落锁**（卧室被他人开锁进入后，下一个时间阶段即恢复上锁）。**反派**持有任一来源时，可在自由活动开始前消耗一次【暴力破解】拉电闸停电（见 §7.5）——平民的【暴力破解】不能用于停电。
- 【信号干扰】：自由活动或晚间休息进入监控室后使用，指定"某个时间段 × 某个场所"的监控记录，添加、替换或移除**其中一条**进入记录（一次只能改动一条）。篡改后的记录对所有人（含公开宣读）生效。

## 4. 道具一览（14 种）

除标注外，每个道具限用 1 次，用后销毁。道具可在**每天聚会结束后**（自由活动/晚间休息）向同房者**当面赠送**（对方可拒绝；明亮房间同房者看得见、黑暗房间无人知晓——见 §7.5/§7.7 与 §9.6）。

### 凶器（4 种）

仅杀手可用以杀人（§7.6）。平民持有凶器仅可用于自卫——自卫克制：枪防刀与棍、刀防棍、棍防刀、枪无法被武器自卫；自卫不消耗凶器。

| 凶器 | 次数 | 效果 |
| ---- | ---- | ---- |
| 左轮手枪 | 1 | 持枪者面对刀/棒球棍的袭击时可自卫 |
| 刀 | 1 | 持刀者面对棒球棍的袭击时可自卫 |
| 棒球棍 | 1 | 持棍者面对刀的袭击时可自卫 |
| 不明药剂 | 1 | 药毒两用：作为凶器仅杀手可用以杀人（仅「急救箱」/【敏捷闪避】/药用的不明药剂可防御，武器无法自卫）；任何持有者遇袭时可将其当作药使用，效果等同「急救箱」（防御一切袭击，含不明药剂本身；也可救治同在现场的其他人），用后消耗 |

### 通用道具（5 种）

平民通用道具池只含本节道具（§2 车道）。

| 道具 | 次数 | 效果 |
| ---- | ---- | ---- |
| 急救箱 | 1 | 面对任何凶器（含不明药剂、环境凶器）可自卫；也可用于同在现场的其他人 |
| 手电筒 | 2 | 身处黑暗房间（地下室/停电房间/夜间卧室）时可选择使用：本阶段该房间不视为黑暗——房间内所有人互相可见、可正常交谈、谋杀按亮房条件判定（使用时机：进入结算后的手电筒判定，见 §7.5/§7.7） |
| 测谎仪 | 1 | 等同【看破伪装】 |
| 鲁米诺试剂 | 1 | 等同【现场调查】 |
| 窃听器 | 2（收听） | 自由活动或晚间休息，在你所在的非卧室房间作为房间行动秘密放置（含会客室——它是唯一能**听到会客室交谈**的手段；监控只记录谁进入，听不到谈话）；只记录放置后发生的交谈。之后任意一天**晚间休息**，你身处自己卧室时可收听一次：获得当天自由活动时段该房间内、放置后发生的全部交谈记录 |

### 反派道具（3 种）

仅反派可用；由帮凶开局持有其一，或经保险箱开出（§2）。

| 道具 | 次数 | 效果 |
| ---- | ---- | ---- |
| 可疑的粉末 | 1 | 等同【伪造证物】 |
| 裹尸袋 | 1 | 等同【转移尸体】 |
| 病毒 U 盘 | 1 | 等同【信号干扰】 |

### 特殊持有

| 道具 | 次数 | 效果 |
| ---- | ---- | ---- |
| 万能钥匙 | 2 | 提供【暴力破解】×2（见 §3.1 词条）。固定由杀手持有（§2），不占其凶器配额 |
| 螺丝起子 | 1 | 提供【暴力破解】×1（见 §3.1 词条）。固定由一名平民开局持有（§2） |

## 5. 房间

| 房间 | 锁 | 人数上限 | 环境凶器 |
| ---- | ---- | ---- | ---- |
| 会客室 | 白天无锁；入夜自动落锁（停电时失效，第 4 天起不再上锁） | 不限 | 无 |
| 书房 | 无锁；保险箱上锁 | 3 | 雕像 |
| 监控室 | 上锁 | 2 | 无 |
| 地下室 | 无锁；永久黑暗 | 3 | 电线 |
| 卧室（每人一间） | 白天不开放；夜间本人自由进入，非本人需开锁或被邀请 | 2 | 无（但夜间黑暗，见下） |

- 开锁手段统称【暴力破解】（黑客/机械师的职业技能或道具「万能钥匙」/「螺丝起子」，见 §3.1 词条）。书房/监控室/地下室的门与保险箱被打开后**永久保持开启**；**会客室与卧室每天夜间重新落锁**（卧室被他人开锁进入后，下一个时间阶段即恢复上锁）。**停电期间所有门锁失效（保险箱除外）；供电恢复后，卧室重新上锁。**
- 第 4 天起，除卧室外所有门锁自动打开。但封闭空间技能仍可使用。
- **会客室**：白天会议场所，自由活动时间同样开放。壁炉长明——**永不黑暗**（停电也不受影响）。监控覆盖其门口（§9.1）。**桌上物品**：开局时桌上放有「左轮手枪」（§2）；遗嘱中未指定归属或被拒收的道具也会放回桌上（§7.3）。白天任何人不能拿取桌上物品（开放大厅、众目睽睽）；夜间身处会客室且室内只有你自己时，可取走一件（取用行为无人看见，但桌上物品的变动次日清晨公告）。**反派谋杀临时取用**：反派（杀手）在会客室发动谋杀时，可将桌上凶器视同环境凶器临时取用——无需事先持有、无需动作，用后消耗（消耗记入次日清晨的桌上物品变动公告）。**夜间归宿可选会客室**：入夜大门自动落锁——【暴力破解】可开锁进入（开锁后当夜他人可随入；夜锁每天重新落下）；停电期间门锁失效，任何人可直接进入。夜宿人数不限；大厅明亮，谋杀按亮房条件判定（§7.6）；夜宿者 ≥2 人时睡前可围炉夜谈（即亮房正常交谈，§7.7）；**夜宿者名单次日清晨公开**。【封闭空间】不能对会客室使用。
- **卧室白天清场**：白天会议结束（进入自由活动）后，卧室一律上锁，任何人（含本人）不得进入或逗留，直至晚间休息。
- **卧室夜间黑暗**：晚间休息时卧室没有照明，一律视为黑暗房间（谋杀条件放宽至非反派 ≤2、空手谋杀豁免附加条件、房内行为不可见、受邀组合可摸黑低语——见 §7.6/§7.7）。黑暗中非反派不知道房内有谁；反派仍能知道在场者的具体身份，但也仅限于知道人员，其他黑暗效果不变（见 §9.5）。
- **地下室**：永久黑暗。黑暗房间内无法进行交谈；其中的谋杀不设非反派人数限制（房间容量仍是硬约束，见 §7.6）。停电后，任何人可前往地下室修复发电机，成功则供电恢复（停电结束）；**无人修复则停电一直持续（跨日延续），不会自动恢复**。
- **监控室**：进入可查看监控记录（见 §7.2 与 §9）。
- **书房保险箱**：打开者获得其中道具（内容开局已全员公告，见 §2；非黑暗时同房者看得见开箱行为与取走的道具，黑暗中无人知晓）。
- **环境凶器**：书房雕像 / 地下室电线。杀手在场满足谋杀条件时可使用，不限次数；目标无法用武器自卫（急救箱/闪避仍可防御）。武器伤痕结论为"雕像"/"电线"——会直接暴露案发房间。

## 6. 时间轴与行动顺序

一天 = 三个时间阶段：

| 阶段 | 位置 | 可否行凶 |
| ---- | ---- | ---- |
| 案件调查 + 公共发言 + 投票（合称"白天会议"） | 会客室（全员） | 不可 |
| 自由活动 | 会客室 / 书房 / 监控室 / 地下室（白天卧室清场） | 可 |
| 晚间休息 | 自己卧室 / 他人卧室 / 会客室 / 书房 / 监控室 / 地下室（与自由活动同构，§7.7） | 可 |

- **谋杀从第 1 天自由活动起开放**，普通谋杀、舞台魔术与延时装置均按各自条件执行；第 1 天没有投票，"公共发言"时段改为**侦探竞选**（见 §7.4）。
- **第 6 天是终审日**：只进行白天会议（案件调查/公共发言/交换/投票），没有自由活动与晚间休息；终审投票结束后仍无阵营获胜，主神降临（见 §8）。
- 行动顺序：第 1 天完全随机；之后每天开始时，将顺序首位移到最后。
- 顺序靠后者在行动前可以看到顺序靠前者的公开声明（如白天房间去向声明、发言内容）；房间的开锁与进入结果在去向声明收齐后统一结算（§7.5）。

## 7 阶段细则

### 7.1 清晨与案件调查

- 每天清晨，主持人公告：上一日（自由活动与晚间）发生的全部**死亡**及案发房间——有报案人时一并刊出（报案人 = 此前进入现场发现尸体并选择报案的人；无人报案则不刊出）。谋杀未遂也会公告（"某人遇袭但幸存"，不公布袭击者与方式）。**死亡与未遂在发生时不即时公告——没人知道白天或夜里是否出过事，直到次日清晨**（进入现场者可提前私下发现，见 §7.6"发现与报案"；遇袭的目标仍会当场私下得知）。**公告不含事发时段，时段只能由调查获知**。
- 若案发房间当时上锁，强制打开并公告此事实。
- 死者的职业若从未公开过，此时公开（身份不公开——只有投票出局才揭示身份）。
- 夜宿会客室者名单此时公开（见 §5）。
- 会客室桌上物品的变动（夜间被取走 / 遗嘱放回）此时一并公告。
- **已永久开启的门与保险箱清单**此时一并公告（谁都可以走近看出门没锁——这只是台账追认）。
- **监控公开**：主持人公开宣读原始监控记录：**案发当日全天（自由活动 + 晚间休息两个时段）**× 两个场所（案发房间 + 死者卧室）的进入者名单。监控只记录"进入"，不记录房间内的行动和对话。
- **调查自荐**：任何持有【现场调查】/「鲁米诺试剂」/【犯罪侧写】的角色均可申请调查，各自选定一项内容；结果**私下告知本人**，由本人决定是否公布、隐瞒或撒谎。
- 一天内多起案件时，每起案件都可被调查；同一起案件同一调查项可被多人重复验证。**已发生的案件在之后的每个清晨均可继续调查**（不限于案发次日；调查对象即此前被谋杀的死者，以受害者名字指认）。
- 尸体上未被拿走的未使用道具此时被收走封存，随后由死者的遗嘱（"死者留下的字条"）指定归属（见 §7.3）。

### 7.2 公共发言

- 第 2 天起，每天按行动顺序每人发言一次（**侦探末置发言**；第 1 天该时段为侦探竞选，见 §7.4）。
- 发言内容不限：分析、指控、质疑、声明、辩护均可；可向顺序靠后者提问。
- 发言结束后（第 2 天起）进入投票（§7.3）。道具赠送不在会议中进行——每天聚会结束后（自由活动/晚间休息）向同房者当面赠送，见 §7.5/§7.7 与 §9.6。

### 7.3 投票与出局

- 第 2 天起，每天公共发言后投票。可弃权。**侦探的一票计 1.5 票**，其余人各计 1 票。得票**超过**当前存活人数一半者出局（平票、未过半则本次无人出局）。
- 出局者先发表**遗言**（可以撒谎；若有未使用的遗留道具，在遗言中一并立**遗嘱**：逐件指定归属，接收人须为存活玩家），随后主持人公布其**身份（平民/帮凶/杀手）与职业**。
- 若出局者是杀手：私下通知帮凶继任杀手。
- **遗嘱**：出局者与当天尸体上封存的未使用道具，由本人逐件指定归属——被谋杀者以"死者留下的字条"形式于次日清晨指定。每件道具的接收人可当场**拒收**；接受的道具**当天即可用**。遗嘱的道具名、来源与去向全部公开。**立遗嘱时可附言——遗言与死者字条的内容同样公开**。**道具不会被丢弃**：未指定归属或被拒收的道具不销毁，一律放回会客室桌上（§5 桌上物品）。侦探出局时，侦探徽章也随遗嘱指定归属（见 §7.4）。
- **武装指认**（第 2 天起，即首次投票起）：平民指认某人为杀手——**指认正确 → 被指认的杀手出局**（遗言→身份公布→遗嘱，流程同投票出局；帮凶私下继任杀手，游戏继续。若帮凶已不在，反派全灭、平民获胜）；**指认错误**（所指为帮凶或平民）→ **指认者出局**（公众由此可知被指认者不是杀手）。**发动时机**（均在投票结算后、出局执行前）：① 一次投票未产生出局者时；② 投票将导致**最后一名平民**出局时——该平民在出局执行前仍可发动（背水一战）。每次投票至多接受一次指认（按行动顺序，先声明者优先）；**指认消耗武器（等同攻击）**——自己的武器扣一次次数（用掉即销毁）；临时取用的桌上凶器用掉即消耗、不再放回桌上（无论对错）。**指认者公开发表一句指认宣言。**资格细则：**武装指认仅限平民**；**有侦探时仅侦探本人可行使**（侦探须持有武器——左轮手枪/刀/棒球棍；侦探若为反派则本局无人可指认，反派自己心里清楚）；**没有侦探时**，持有武器的平民可指认，桌上凶器仍在会客室桌上时任何平民也可**临时取用**桌上凶器进行指认。

### 7.4 侦探（第 1 天竞选产生）

- **竞选流程**（第 1 天"公共发言"时段）：
  1. **声明轮**：按行动顺序，每人作一段简短发言并宣告参选或不参选（可顺带宣告自己的职业与道具——可以撒谎，但谎言会留档）。
  2. **密封退选**：若参选者 ≥2 人，参选者各自私下决定继续参选或退选（互不可见，结果一齐公布）；退选者同样没有投票权。各人可附一句理由，随结果一齐公布。
  3. **投票**：留任候选人只剩 1 人则直接当选；超过 1 人时由**自始未参选者**（不含退选者）投票，每人 1 票，得票最多者当选。票型不公开，但投票人可附一句理由，开票后公布。
  4. 无人报名、候选人全部退选、全员参选（无人持有投票权）或投票平票 → **本局不设侦探，不再补选**。
- **职权**：① 当选时获得桌上凶器「左轮手枪」（**侦探佩枪**，公开公告）；② 公共发言末置发言（第 2 天起）；③ 投票时一票计 1.5 票（第 2 天起）；④ **武装指认垄断**：有侦探时仅侦探可进行武装指认（§7.3）。佩枪本身是普通道具：可赠送他人、被谋杀时可被杀手缴获（§7.6）、被票出时随遗嘱分配、用于武装指认时同样消耗（§7.3）。
- **警徽传承**：侦探出局（被谋杀 / 投票出局 / 武装指认失败）时，侦探徽章随遗嘱一并处理——由本人指定一名存活玩家继任（接收人可拒收）；未指定或被拒收则销毁，本局不再设侦探。
- 侦探不是调查垄断者：任何有调查能力的人都能自查（见 7.1）。

### 7.5 自由活动

1. **停电声明（拉电闸）**：反派可在本阶段开始前秘密声明停电——消耗一次【暴力破解】（职业技能/「万能钥匙」/「螺丝起子」任一）拉开电闸制造过载（电闸不在地下室，无需前往）。平民的【暴力破解】不能用于停电。**停电的发现**：停电后每位玩家在抵达自己所选房间的那一刻才各自发现（灯骤然熄灭、四周一片漆黑、门锁全部失效——留在会客室者则看到走廊灯火尽灭）——在此之前，他人的进入结果不会向你暴露停电；全员进入房间后主持人才向众人正式公布。
2. **去向声明**：所有人按行动顺序依次声明去向：**会客室 / 书房 / 监控室 / 地下室**（白天卧室一律清场，不可选择）。此轮只确定意向，不移动任何人。**顺序靠后者在声明前可见顺序靠前者的去向声明与邀请**。可同时向顺序靠后者发出同入邀请（对方可选择更改自己的目的地）；**同入邀请成立时，邀请者会知道对方已到来**（即使在黑暗房间，你也听得见应邀者进来），邀请未成立则不会有任何通知。
3. **开锁行动轮**：去向收齐后，对每一间有玩家准备进入的上锁房间，主持人按行动顺序逐一**私密询问**拟进入者中持有【暴力破解】手段的人是否愿意使用；首位愿意者消耗一次手段并开门，成为该房间的开锁者。此轮只处理门锁与剩余次数，不处理位置、容量或邀请；不愿使用者不消耗次数。若无人愿意开门，门保持上锁。
4. **进入与停电结算**：每个房间由开锁者优先进入，其余人仍按行动顺序；随后正常判定人数上限、邀请、【封闭空间】等进入条件。门已在开锁轮打开时，顺序靠前但自己无开锁手段的人也能进入；房间上锁而本轮无人开门、满员、被【封闭空间】挡住或选择无效者无法进入，默认滞留会客室。停电生效时，除会客室外所有房间视为黑暗（地下室恒为黑暗）；**所有门锁失效**（保险箱除外）；**监控停止记录**（空白期，不回溯、供电恢复后恢复记录）。**停电不会自动结束**：一直持续到有人在地下室修复发电机为止——无人修复则跨日延续（次日及之后依然停电）。
5. **手电筒判定**：进入结算后（停电公告之后），身处黑暗房间且持有「手电筒」的玩家按行动顺序逐一决定是否使用——点亮的房间本阶段视为明亮：所有人互相可见、可正常交谈、谋杀按亮房条件判定；已被点亮的房间不再重复询问。
6. **房间交谈**：同房者可自由交谈，每人按行动顺序发言一次，后发言者能看到本房间先发言者的发言（含会客室）。**黑暗房间内无法交谈——例外：同入邀请成立的组合互知在场，可摸黑低声交谈；此时房间内所有在场者（含他们不知道的潜伏者）都能听到内容，交谈者不会知道是否被旁听**（与 §7.7 夜间密谈同口径）。进入结算时若有人被延时装置击杀，该房间本阶段跳过交谈。
7. **房间行动**：使用房间设施（查监控 / 修发电机 / 开保险箱等）、**当面赠送道具**（§9.6：限同房者，对方单独回应接受/拒绝）与**报案**（身处有未公告尸体的房间时可用，见 §7.6「发现与报案」）。每人每轮房间行动只能选择一个动作，多报会整批驳回。非黑暗时，这些行为会被同房者看见；黑暗中则无人知道是谁做的。
8. **谋杀窗口**：房间行动结束后，杀手与反派魔术师各自单独决定是否动用本阶段谋杀机会（§7.6）。每阶段一次机会，放弃则本阶段不能再杀；与房间行动相互独立，谋杀不消耗房间行动次数、房间设施也不消耗谋杀机会。

### 7.6 谋杀判定

**发动条件**（杀手/反派魔术师在**谋杀窗口**声明发动——房间行动结束后的独立环节，每阶段一次机会——自由活动与晚间休息各自独立一次，放弃则本阶段不能再杀）：

- 在场非反派角色数：正常 ≤1；黑暗房间不设人数限制（房间容量仍是硬约束）。
- **空手谋杀**还须满足以下**之一**：① 帮凶在场；② 本人体格 ≥ 目标体格；③ 本人男、目标女。黑暗房间中（含夜间卧室，见 §5）空手谋杀无任何附加条件。
- **凶器谋杀**：无条件（不明药剂只能由杀手使用）。会客室桌上的凶器可被反派临时取用（见 §5 桌上物品）。
- **环境谋杀**（雕像/电线）：无条件。

**自卫判定**：目标持有能克制该凶器的武器 / 「急救箱」/【敏捷闪避】时，谋杀自动失败（自动触发，无需目标声明）。克制关系：枪←无效；枪防御刀与棍；刀防御棍；棍防御刀；**空手谋杀不会被凶器克制**，但仍可被「急救箱」/【敏捷闪避】（含药效等同的药用「不明药剂」）抵消导致失败。急救箱与敏捷闪避防御一切（含不明药剂、环境凶器、空手）；不明药剂只被急救箱/敏捷闪避防御。**延时装置与舞台魔术没有任何方式防御。**

**失败后果**：目标得知"有人遇袭"（自己幸存，必然知情），但不知道袭击者是谁；在场的其他人只听到些许奇怪的动静，不知道发生了什么、是谁造成的。杀手也无法分辨失败原因（是武器、急救箱还是技能）。未遂计入"无杀倒计时"（见 §8）。

**成功后果**：

- 若现场没有其他非反派角色：杀手获得尸体上全部未使用道具；**身处案发现场的**杀手/帮凶可发动毁证类反派技能或道具（伪造痕迹/销毁证物/伪造证物/转移尸体等）——毁证必须亲自动手，场外反派不会收到通知；**毁证与转移尸体仅限案发当天**：白天的案件当晚仍可前往现场处理，次日清晨案件调查后现场即无法改动。
- 若现场有其他非反派角色：不能拿道具、不能毁证。
- 死亡公告统一在次日清晨发出（见 §7.1；公告不含死亡时段）。
- **发现与报案**：死亡发生时不即时公开。之后第一个进入案发房间的人会当场私下发现尸体（黑暗房间同样触发）——只告知发现者本人；同房的人各自独立决定是否**报案**（房间行动中的独立可选动作，消耗当阶段房间行动名额）：报案者被记录为**报案人**，随次日清晨公告一并公开；不报案则无人知道你知情（你可以照常交谈、守口如瓶，或当场把事情说出去）。凶手与帮凶同样可以回到现场发现尸体并报案。同一房间多人发现可多人并列报案。

### 7.7 晚间休息

晚间休息与自由活动**结构相同**：**去向声明 → 开锁行动轮 → 进入结算 → 手电筒判定 → 房间交谈 → 房间行动**——只是合法去向、锁与明暗不同。所有人的选择**互相不可见**（你看不到别人去了哪里）。晚间休息是发现白天凶案的唯一窗口：若所选房间有尚未公告的尸体，进入者当场私下发现（见 §7.6「发现与报案」）。

1. **选择去向**：按行动顺序依次秘密声明，收齐后先进行开锁行动轮，再统一结算进入：
   - **回自己卧室**（默认）：夜间开放，免费进入。
   - **前往其他房间**：会客室 / 书房 / 监控室 / 地下室 / 他人的卧室。
   - **同入邀请**：可邀请一名顺序在自己之后的玩家同去你的目的地（对方可改选）。邀请成立则互知在场（黑暗中也知道）；对方没来则不会有任何通知。
   - **密道**：反派建筑师可声明经密道前往会客室/书房/监控室/地下室之一（见 §3【建造密道】；不受人数上限与"平民慎入"限制）。
2. **锁与开锁轮**：开锁轮与白天相同——按行动顺序私密询问拟进入者，首位愿意消耗【暴力破解】手段者开门并在进入轮优先，其余人按原顺序；自己无手段但顺序靠前的人不会被提前劝退。他人卧室上锁——对所有人一视同仁（含反派）：需【暴力破解】手段或受邀才能进入（被他人开锁后，下一个时间阶段恢复上锁）；会客室入夜自动落锁（手段或停电/第 4 天起免费进入，开锁后当夜他人可随入，夜锁每天重新落下）；监控室上锁（首开需手段，开后永久开启）；书房/地下室无锁。**停电期间所有门锁失效（保险箱除外）。**
3. **明暗**：**卧室夜间黑暗**（§5）；地下室永久黑暗；会客室永不黑暗；书房/监控室夜间明亮（停电时黑暗）。
4. **人数上限**：书房 3 / 监控室 2 / 地下室 3 / 卧室 2 / 会客室不限（与白天一致）。满员后他人无法进入——卧室住满 2 人天然挡住后来者（含杀手）。
5. **平民慎入**：平民不敢**非受邀**进入**已有他人**的书房/监控室/地下室——进入失败并私下得知"已经有人了，出于安全考虑，你没有进入"。被邀请者与反派不受此限（反派进入他人卧室仍须开锁或受邀）。
6. **进入失败**：功能房/会客室失败会私下告知简要原因（上锁/已满员/已有他人）；进入他人卧室失败仅告知"无法进入"。无法进入者默认回自己卧室。
7. **手电筒判定**：进入结算后，身处黑暗房间（夜间卧室/地下室/停电房间）且持有「手电筒」的玩家按行动顺序逐一决定是否使用——点亮的房间本阶段视为明亮：所有人互相可见、可正常交谈、谋杀按亮房条件判定。在自己卧室也可以使用——能照出偷偷摸进来的人，对方若试图空手谋杀也无法绕过附加条件。
8. **房间交谈**：亮房正常交谈；黑暗房间无法交谈——例外：同入邀请成立的组合可摸黑低语，此时房间内所有在场者（含他们不知道的潜伏者）都能听到内容，交谈者不会知道是否被旁听（与 §7.5.6 同口径）。卧室两人密谈、会客室围炉夜谈均按此口径。进入结算时若有人被延时装置击杀，该房间本阶段跳过交谈。
9. **房间行动**：查监控（监控室）/ 篡改监控（监控室）/ 修发电机（地下室）/ 开保险箱（书房）/ 收听窃听器（自己卧室，见 §3.1）/ 取桌上物品（会客室独处，见 §5）/ 使用技能与道具 / **当面赠送道具**（§9.6：限同房者，对方可拒绝）/ **报案**（身处有未公告尸体的房间时可用，见 §7.6「发现与报案」）。每人每轮房间行动只能选择一个动作，多报会整批驳回。非黑暗时这些行为会被同房者看见；黑暗中则无人知道是谁做的。
10. **谋杀窗口**：房间行动结束后的独立环节（见 §7.6）——杀手/反派魔术师单独决定是否动用本阶段谋杀机会；卧室夜间黑暗 → 非反派 ≤2、空手豁免；进入空房间没有目标，不消耗机会。
11. **夜宿会客室**：夜宿者名单次日清晨公开（大厅无隐私）；桌上物品变动次日清晨公告（§7.1）。

## 8. 胜负条件

- **平民胜利**：杀手与帮凶全部出局（投票或武装指认）；或无杀倒计时完成。
- **无杀倒计时**：自第 2 天起算，第 1 天是否出手不影响起始进度。此后若连续**两个完整天**（自由活动+晚间休息）没有任何谋杀行为，则下一个清晨平民直接获胜。倒计时启动后，谋杀行为 = 真正进入攻击判定（击杀成功或被防御的未遂）；未发动（含进入空房间没有目标）不计入。
- **反派胜利**：所有平民死亡或被投票出局。（残局不打折扣：哪怕只剩 1 名平民，也要真正杀光或票光才算赢——决斗与反杀都可能发生。）
- **主神胜利**：第 6 天终审投票结束时仍无阵营获胜（包括从未发生任何谋杀行为的情况），则**全员失败，主神获胜**。

## 9. 关键裁定速查

1. **监控**：只记录"某时间段谁进入了某场所"，不记录房间内行为。监控覆盖所有房间门口（含会客室）；监控室上锁（首开需【暴力破解】手段），人数上限 2。记录可被【信号干扰】/「病毒 U 盘」篡改，篡改对所有人可见的宣读结果生效。经密道者的进入不留记录（记录上此人一直在自己卧室）。**停电期间监控缺失（不记录）；清晨宣读时缺失会注明。清晨公开宣读覆盖案发当日全天（自由活动 + 晚间休息两个时段）×（案发房间 + 死者卧室）。**
2. **看破伪装**：只验证"职业、道具、技能、行踪"四类声明是否为谎言。"我是清白的"等声明不在验证范围内。行踪以监控记录为准；存在停电空白时，无记录不构成谎言证据（判"无法验证"）。
3. **死亡公告**：谋杀与未遂**不在发生时即时公告**，统一在次日清晨公告"谁死了/谁遇袭 + 案发房间"，有报案人时一并刊出；公告不含事发时段——时段只能由调查获知（毁证因此可能伪造死亡时间）。进入案发房间者会当场私下发现尸体（见 §7.6「发现与报案」）；遇袭的目标仍会当场私下得知。
4. **身份揭示**：只在**出局**时发生（投票出局、武装指认正确处决杀手、武装指认失败——遗言在揭示之前）；死亡不揭示身份，只揭示职业（若此前未公开）——但遗留道具随遗嘱公开（§7.3）。
5. **黑暗**：地下室永久黑暗；会客室永不黑暗；**卧室夜间黑暗**；停电期间除会客室外全部黑暗；**手电筒点亮的房间本阶段不视为黑暗**（进入结算后的手电筒判定，§7.5/§7.7）；黑暗 = 房间交谈无法进行（例外：同入邀请成立的组合可摸黑低语，全体在场者含潜伏者都能听到，§7.5.6/§7.7）+ 谋杀不设非反派人数限制（房间容量仍是硬约束）+ 空手谋杀豁免附加条件 + 房间内行为不可见。**反派在黑暗房间仍能知道在场者的具体身份；这只是人员信息例外，以上交谈、行为不可见与谋杀判定均不因此改变（帮凶仍无普通主动谋杀权）。**
6. **道具**：默认限 1 次（手电筒、万能钥匙、窃听器收听为 2 次）；转手不影响剩余次数；出局者/死者的未使用道具经遗嘱指定归属，接受后**当天即可用**；未指定归属或被拒收的道具不销毁，放回会客室桌上（见 §5 桌上物品）。**当面赠送**：每天聚会结束后（自由活动/晚间休息），可向同房者赠送道具——对方单独回应接受/拒绝；明亮房间同房者看得见交易（道具名不公开），黑暗房间无人知晓。
7. **侦探**：第 1 天竞选产生（声明轮 → 密封退选 → 未参选者投票；平票/无人参选/全员参选则本局无侦探，不补选）；职权=桌上佩枪 + 末置发言 + 1.5 票权 + 武装指认垄断；出局时警徽随遗嘱传承或销毁，佩枪按普通道具处理（可被缴获/赠送/遗嘱分配）。
8. **次数与合法性**：主持人掌握全部技能/道具剩余次数；声明使用不存在的手段、次数耗尽的技能或不满足条件的动作，会被直接驳回并私下告知本人（可当场重新声明一次；其他人不会知道）。
9. **桌上物品**：开局时桌上放有「左轮手枪」；遗嘱未指定/被拒收的道具也放回桌上。白天不可拿取；夜间独处会客室者可取走一件；反派谋杀可在会客室临时取用桌上凶器（视同环境凶器，无需持有，用后消耗）；变动次日清晨公告。
10. **昼夜统一进入结构**：自由活动与晚间休息均采用去向声明 → 独立开锁行动轮 → 进入结算（开锁者优先，其余按行动顺序）→ 手电筒判定 → 房间交谈 → 房间行动 → 谋杀窗口（独立环节，不占房间行动）；白天靠后者可见前者的去向声明，晚间的去向互相不可见。他人卧室上锁（对所有人含反派一视同仁，受邀除外）；卧室夜间黑暗；平民非受邀不敢进入已有他人的功能房（被邀请者与反派豁免）；卧室满 2 人天然挡住后来者（含杀手）；每阶段独立一次谋杀机会。
