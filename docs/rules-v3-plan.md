# 规则 v3 代码实施计划

> 规则书侧已定稿：`rules/rules-6.md` v3（8 人局 rules-8 本包不动）。
> 本文件是代码侧实施清单。来源：会客室设计讨论 + game/42 复盘（首局完整对局，旧规则）。
> 实施顺序建议：引擎 → 编排器 → 测试 → 文档；完成后先跑 `python -m unittest discover -s tests`，再跑一局 mock 全流程，最后真实对局验收。

## A. 引擎（src/engine/）

### A1. 会客室房间化
- `state.py`：`PUBLIC_ROOMS` 拆分——功能房（书房/监控室/地下室，监控覆盖、夜间开放）与会客室（白天开放）分两个常量；`is_dark` 加会客室恒 False；`record_entry` 跳过会客室（无监控）。
- `core.py enter_rooms`：合法目标 = 功能房 + 会客室（白天）；容量：会客室不限，功能房保持 3；卧室在自由活动一律非法。
- `ledger.py seal_room`：目标为会客室时驳回。
- 谋杀/交谈/毁证等按房间判定的逻辑对会客室按普通亮房处理（无特殊分支）。

### A2. 白天卧室清场
- `enter_rooms`：自由活动阶段目标是任何卧室 → 视为非法，由编排器兜底为会客室并私密告知本人（"卧室白天不开放，你滞留在会客室"）。
- 引擎侧保留夜间卧室逻辑不变。

### A3. 密道夜间化（重写 `ledger.py set_passage/use_passage`）
- `set_passage`：不再绑定出口房间（参数去掉 room，或忽略）；开局义务仍要声明。
- `use_passage`：阶段改为晚间休息；出口由使用时指定（书房/监控室/地下室，驳回卧室与会客室）；
  进入条件复用谋杀人数条件（出口房间在场非反派 ≤1，黑暗 ≤2）——不满足则当晚失败，**密道保留、不暴露**；
  成功：`passage_stealth` 照旧（监控无痕）、消耗当夜谋杀机会（若杀人）、密道损毁；整局至多成功一次。
- 与夜袭/夜间房间行动互斥（编排器菜单层保证每人当夜只选一项）；不占夜间房间 1 人名额。
- 密道进入后与目标同房 → 夜间谋杀窗口（现有 `night_murder`）正常提供动手选项，引擎 `murder()` 全量校验。

### A4. 窃听器
- `gamedata.py`：收听次数 1 → 2。
- `bug_listen`：阶段改晚间休息 + 身处自己卧室；其余校验不变。

### A5. 武装指认放开
- 去掉第 4 天起条件：投票未产生出局者即可（含第 2 天）。每次投票至多一次不变。

### A6. 监控全量返回
- `view_monitoring`：忽略/删除 period、room 参数，恒返回全部已有记录（公开口径）。
- `detective_monitoring`：保留指定语义；非法 period 驳回时列出当前合法时段。

### A7. 清晨状态行（消灭规则状态幻觉，game/42 复盘项）
- `core.py advance()` 进入清晨的公告追加一行主持人算好的状态：存活人数（各方视角只给总数）、无杀倒计时状态（未启动 / 已连续 N 个完整天无谋杀）、待分配封存道具数。

### A8. 侦探条件化
- `advance()`：仅当 `cases` 非空时设置 `detective = order[0]`，否则 `detective = None`；清晨公告相应省略/说明"今日无案件，不设侦探"。
- `assign_sealed` 平票无侦探 → 销毁（编排器侧已能处理 det=None，核对即可）。

## B. 编排器（src/orchestrator.py）

### B1. 选房菜单与兜底
- 菜单逐一枚举合法房间全名 + 负面清单（"会客室/卧室白天不开放"类明示）；不选/非法 → 滞留会客室 + `tell` 私密告知。
- 会客室加入选房菜单首位。

### B2. 夜间菜单
- 新增：密道（反派建筑师且密道未损毁）、收听窃听器（在卧室且已放置）；同宿密谈说明。
- `night_room`/`night_raid`/`use_passage`/`bug_listen` 互斥语义写进菜单文案。

### B3. 同宿密谈 runner（晚间休息新增环节）
- 归宿结算后：通过留宿邀请同处一室的两人一轮密谈（按行动顺序各一次发言，后发可见先发）；被杀手夜袭进入的卧室跳过。
- 投递：私密 tell + `private/<id>/log.md` 存档 + script.md 记录。
- 密谈后再进深夜谋杀窗口（现有顺序：归宿结算 → 夜间房间行动 → 谋杀；密谈插在结算后、行动前）。

### B4. 窃听器内容真实下发（game/42 复盘 bug）
- 现状：`bug_listen` 回执承诺"内容由编排器提供"但从未投递，导致玩家编造录音内容。
- 改动：`orch` 新增按"天×房间"的房内交谈存档（room_talks 写入时同步）；收听成功后把对应记录 `tell` 给收听者。

### B5. 监控菜单
- `view_monitoring` 菜单去掉参数：`{"type": "view_monitoring"}（返回全部已有记录）`。
- 侦探特权菜单枚举当前合法时段列表。

### B6. script.md 增强
- 每天清晨写"状态一览（全剧透）"表：角色 / 状态（存活、死于第N天、出局）/ 身份 / 职业 / 技能剩余 / 持有道具（含次数）——仅 host 侧，不进任何 prompt。
- 赠送记录去重（现编排器记一行 + route 公告一行，合并为一行含道具名与结果）。
