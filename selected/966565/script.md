# 开局公告

欢迎来到暴风夜。

你们是六名失去记忆的客人。但你们之中隐藏着两个杀手。找出他们并通过投票淘汰他们；否则，他们将会一个一个杀死你们所有人。

大厅的桌上还有我年轻时的收藏：「左轮手枪」.你们中的佼佼者可以通过选举成为侦探，便可获得这把武器，以及更多票权。至于谁能拿到它，就看你们的本事了。

—— 主神

**狄西**：那我也参选。侦探手里那把枪、还有一票顶一票半的分量，太重了，不能稀里糊涂就交到一个人手上。杰米尼愿意站出来是好事，可多一个选择总没坏处。我做事踏实，真选上了就照规矩来，谁有疑点就查谁，不徇私。

豆包 宣告参选侦探
